Lesson Pages 把 `guide-learning` 的讲解写进一份课程网页：每一课一个离线就能打开的 HTML 文件，随课程一段一段长出来。对话里不再出现大段讲解，只留下“去读哪一节”的指路、要你回答的检查题，以及对你回答的反馈。页面上有全流程骨架、按节点排好的讲解、分步演示和对照切换这类可以亲手操作的图，读起来比在对话框里滚动长文字轻松。

## 它和 guide-learning 的关系

讲什么、讲到多深、怎样提问、什么时候进入下一步，仍然完全由 `guide-learning` 决定；Lesson Pages 只负责把同样的内容排成页面、决定哪些放页面哪些留在对话。两者同时工作，不需要你在每一步重复请求。页面不是学习记录：课程进度以 `guide-learning` 的断点为准，理解的证据以你在对话里的回答为准。

## 什么时候会用页面

- 你说“用网页讲”“把这一课做成页面”，或者这一课已经有页面。
- 你的学习者画像里写了偏好课程网页。这时开课确认里会默认提出用页面，你可以说这课不用。
- 一次简单的答疑默认还是在对话里回答，不建页面；你想要时可以要一个答疑页。

随时可以说“这课不用网页”，回到对话里讲。页面出问题时，Agent 会先在对话里继续讲，不让页面耽误学习。

## 一课在页面上怎样进行

1. **开课**：页面先写出这一课要解决什么、全流程骨架和资料指路。需要核对你的基础时，Agent 会在对话里问一个小问题。
2. **每一段**：几个节点的讲解连同一道检查题加进页面。对话里告诉你新增了哪几节、大约读几分钟，并把题目原文发给你。
3. **作答**：你在对话里回答，页面上的这道题随即标为“已作答 · 补差中”。反馈直接写在对话里；需要图、公式或较长推导的补充，会加在页面对应节点下面。
4. **串讲与验收**：所有节点讲完后，页面加上导师串讲和综合验收题。题目答完、差距补上以后，才会在题目下加参考要点。
5. **之后**：页面留在仓库里，可以随时回看。页头的“只看要点”只显示每节的结论、骨架、口述版和题目，适合复习。

页面不会提前写还没讲到的内容，也不会在你作答前给出答案或提示。你想自己先往下读时，可以说“剩下的都写出来”，Agent 会提前写讲解部分，但串讲和验收题仍然等到那一步。

## 怎样打开页面

Agent 会按当前环境给你一种打开方式。学习者画像里只记“长讲解偏好用课程网页”这一条偏好，页面位置和打开方式不写进画像：

- **Agent 在本机运行**：直接用浏览器打开页面文件，之后刷新即可。
- **Agent 在远程机器上**（例如通过编辑器远程开发）：Agent 征得你同意后在后台启动一个只读的本地服务，编辑器会把端口转发到你的电脑，用浏览器或编辑器内置的简易浏览器打开 `http://localhost:8765/…`。页面更新时，底部会提示刷新；会话结束时 Agent 会停掉这个服务。
- **宿主能发布私有网页**：内容会离开本机，必须你明确同意后才会使用。

页面会记住你读到哪里、上次看过哪个版本，新加的部分会标出“新”；这些只保存在你自己的浏览器里。

## 页面里有什么

- **全流程骨架**：整课的主线画成一条地铁线路。讲过的阶段是已通车的站，点一下就到讲它的那一节；被几节讲到的阶段是换乘站，列出这几节；还没讲到的站标着“未开通”、蒙着一层雾，等讲到时雾会散开。每节开头挂一块站牌，写着上一站、本站和下一站。宽屏时目录栏顶上还有一条小地铁，读到哪一节，它讲的那几站就被套住。
- **节点讲解**：每节先给结论，再按机制、设计理由、真实系统、边界、面试口述展开；来源和版本放在页边批注里。中文术语第一次出现时，上方用小字注出英文原名（比如“显存”上注 HBM），方便对照资料和代码；最关键的数字会被一笔圈出来。
- **开场海报**：有的课开头会放一两个超大的数字，点出这一课要解决的矛盾，比如“512 MiB 的矩阵 ≫ 192 KB 的片上存储”；两个数能换算时，下面铺一片格子，亮起的一格是小的量，整片是大的量，差多少倍一眼就看得出。
- **讲解卡片**：对数尺把相差几个数量级的量排在一把尺上，标出相邻两个量差几倍，还可以切到普通刻度，看小的量怎样挤成一团；误区对照把一个常见误解和实际情况并排放，读到时误解被红笔划掉；类比卡先用熟悉的事物打个比方，按一下再沿一道裂口展开，告诉你这个类比在哪里不成立。
- **公式与推导**：重要的公式可以拆开看，每一项都用引线连着一句说明，指向一项，说明一起亮起；需要推导的结论按“下一步”一行行展开，每步变了哪里会标出来，等号上下对齐，结论框起来。
- **执行回放**：讲代码时，可以拖动时间轴或按“播放”看它一行行地跑，正在执行的行亮着，旁边的变量表跟着变，还画出每个变量的走势。表里的数字是真实运行记录下来的。
- **系统结构图**：硬件和软件都画成可以逐层放大的结构图，比如从整张 GPU 放大到 SM 再到处理块；放大后外面几层留在四周，点哪一层就退回哪一层。硬件是电路板和芯片的样子，软件是窗口和模块的样子。
- **可调段落**：有的段落带虚线框和“可调”标签，句子里带 ‹ › 的数可以左右拖动、点按或用方向键换值，后面的结果跟着重新计算；鼠标指向时会列出所有可选的值，第一次读到时页面会在第一个可调的数上提示一下，改过之后可以一键还原。
- **交互图**：放在深色的“实验台”上，和正文的浅色纸面一眼区分开。分步演示可以一步步翻看、点圆点跳转或按“播放”自动走完，对照切换可以比较两种做法，参数探索可以换成真实配置看数量级，读数变化时会平滑过渡。由公式得出的数字由页面实时计算，参数探索还带自检用例；实测得到的数字会注明怎样测的。
- **公式**：按 TeX 排版，和教材里的公式一样清楚；关键量的颜色与正文、代码、图里一致。把鼠标放在一个带颜色的符号上，全页同一个符号会一起亮起，有释义的还会浮出符号表里的解释。
- **代码**：深色代码块，按语言着色，带行号和“复制”按钮；讲到的行会标出，旁边的分条说明指向哪几行，鼠标放上去那几行就亮起来。
- **检查题**：全页最醒目的地方，写明“在对话中回答”。口述题旁边可以有一个计时器帮你练习时长。
- **符号与名词**：随讲解增长的符号表，写明每个符号的含义、维度和单位。
- **学习地层**：页头的“地层”按每次加进页面的先后给内容分层着色，旁边的图例写着每一层加了什么；点一层就只看这一层，复习时能看出这一课是怎样一步步长出来的。拖动图例顶上的滑块，还能回看某一次更新时页面的样子。
- **从对话跳过来**：Agent 在对话里给的链接带着位置，打开时那一块会亮起来、四周暗下去两秒多，一眼就能找到。

## 页面风格

每门课可以选一种风格，同一门课的所有页面保持一致：

- **讲义**（默认）：浅色纸面上的安静讲义，能动手的图和代码放在深色台面上。
- **蓝图**：像一张工程图纸。白底网格纸，封面和实验台是蓝图蓝，标题是空心描边字，标题栏写着图号和版次，新内容用修订三角标出；骨架画成双线管线图。适合系统、硬件、算子和架构类的课。
- **朱批**：像一份被老师批改过的讲义。宣纸、墨色和朱砂三色，节号写成“一、二、”，重点是字下的朱红小圈，页边批注写着“批”，题目后钤一方“第 N 课”的印，检查题像试卷，作答后盖上“已阅”。适合偏阅读、理论和推导的课。

建第一页时告诉 Agent 想用哪种风格；不说就用讲义，课程性质明显时 Agent 也可能在开课确认里提一句。之后想换，直接说“换成蓝图风格”，Agent 会把这门课的页面都换过去，内容不变。三种风格都支持深色模式、手机和打印。

想先看看三种风格的样子，可以用浏览器打开 `skills/lesson-pages/references/sample-pages/` 里的三页：同一课分别用讲义、蓝图、朱批写成的成品。

页面是单个 HTML 文件，不依赖网络、不加载外部字体或脚本，深色模式、手机和窄窗口都能读，也可以直接打印。公式和代码着色在写入页面时就已排好，这一步需要 Agent 所在的机器装有 Node；没有 Node 时，公式改用简单的上下标写法。如果你觉得动效分散注意力，打开系统的“减少动态效果”，页面会直接显示全部内容。

## 文件放在哪里

页面放在一个专门的目录里，通常和课程账本平级，例如 `<课程目录>/pages/`，文件名就是这一课的 ID。第一次建页前，Agent 会在开课确认里说明路径，你确认后本课的追加自动进行。Agent 不会覆盖已有文件，不会修改你以前手工做的图解页，也不会替你暂存、提交或推送。

使用受管配置的仓库可以在 `lesson-pages` 的配置里登记页面目录，它必须和 `guide-learning` 一起配置，并且不能与 `guide-learning` 映射的写入目录重叠。登记后脚本只在这些目录里写页面；配置只说明位置，不代替每课的确认。

## 你需要做什么

- 想用页面时告诉 Agent，或者在学习者画像里写下偏好。
- 在开课确认里确认页面路径和打开方式。
- 读页面上新增的部分，在对话里回答检查题；某处没看懂，直接说节点编号或图号。
- 觉得页面太长、太密或对话里还是太多字时说出来，Agent 会调整，也可以把这种偏好记进画像。

## 与其他 Skill 的关系

页面可以被学习记录引用，但只有你明确指定时，才会作为文章、记忆卡片或英语回顾的素材。完整的组合方法见[学习类 Skill 组合使用指南](../learning-skills-user-guide.md)，教学本身见 [`guide-learning` 说明](guide-learning.md)。
