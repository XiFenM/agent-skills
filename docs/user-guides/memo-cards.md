Memo Cards 把已经核验、值得反复强化的英语或技术材料整理为适配 Markji 3.8+ 的受管 Markdown 与 XLSX 文件集。它负责选材、拆卡、去重和安全发布，不负责把内容直接导入 Markji。

## 什么时候适合使用

- 希望预览、创建、刷新或去重墨墨记忆卡。
- 已经有稳定的学习要点、真实英语错误、成熟文章或结构化学习记录。
- 希望把技术知识区分为稳定概念和带版本范围的实现事实。

制卡必须由用户明确提出。学习结束、其他 Skill 的建议或素材已经准备好，都不会自动触发制卡。

## 制卡流程

1. **确认范围。** 用户指定素材、目标卡片集合（collection）、目标文件，并说明采用默认的“精选”还是“完整转换”。完整转换仍只包含达到质量要求的内容。
2. **筛选素材。** Agent 检查结论是否稳定、来源是否可追溯、事实是否已经核验，以及内容是否值得间隔复习。猜测、冲突、遗留问题和未核验的时效信息只会出现在阻止原因中。
3. **整理卡片。** Agent 先把材料拆成单一、短促的回忆目标，再按需形成单点卡、机制卡或综合口述卡，
   并标明常青知识或版本范围。复杂答案按“结论／要点／边界”分层，由工具生成受控版式；工具同时负责
   逻辑身份、模板、去重和格式校验。
4. **展示预览。** 用户会看到纳入卡片的短题面与内容层级，延后、阻止、重复或冲突的候选，以及目标
   文件的准确差异和风险；预览不会只报告卡数或模板名。
5. **确认并保存。** 没有写入授权时停在预览。低风险新建可以沿用当次明确的保存请求；接管旧文件、人工修改、来源或模板变化、删除和跨文件刷新等情况，需要查看差异后再次确认。
6. **本地验证与手动导入。** 保存完成后，Agent 验证 Markdown 与全部 XLSX。用户随后在 Markji 中选择对应模板，逐个上传按模板拆分的 XLSX，并自行管理远端卡片。

## 用户需要做什么

- 提供明确的素材范围，并在需要保存时选择准确目标。
- 决定精选或完整转换，检查哪些候选被纳入、延后或阻止。
- 对有风险的更新、冲突或旧文件接管确认准确差异。
- 在 Markji 中选择匹配模板，上传对应 XLSX；不同模板使用不同文件。

## 卡片怎样保持易读

版式不会替代拆卡。问题连续折成多行，或答案成为一整段长文字时，Agent 会先缩短问题、删除无关背景，
并检查是否应拆成多张卡；不会只靠缩小字号或增加颜色。复杂答案先给直接结论，再把必要步骤或比较轴
逐行列出，最后单独说明条件和失效边界。场景与来源放在末尾并弱化，只保留足以回查的短标签。

卡片只使用少量固定语义色：绿色表示正确内容或结论，橙色表示边界，红色只表示已核验的真实错误，
灰色表示来源等元数据。Agent 不会把原始 Markji 标记写进卡片字段；公式、链接和多行结构都由工具从
受控内容生成。结论与边界的短标签可随卡片语言调整，但在同一 collection 中保持一致。

需要核对 `T`、`P`、`F`、`Choice`、`E` 或 `Pic` 的原始边界与示例时，可以查阅随 Skill 保存的
[《墨墨记忆卡「内容语法」说明》PDF](../../skills/memo-cards/references/markji-content-syntax.pdf)。这份
固定快照用于解释内容语法，不替代 Markji 当前的表格导入帮助或客户端实测。

## 产物与边界

输出是一个本地受管 artifact set：Markdown 保存来源、卡片身份、模板、差异审计信息和 XLSX 链接；每个实际使用的模板对应一个可上传的 XLSX，卡片数据不再复制进 Markdown。它不是已经导入的远端卡组，也不是自动上传流程。待复核（`review`）或已归档（`archived`）等状态只描述本地产物，不代表 Markji 中的卡片已经同步变化。

更新时，预览会同时显示 Markdown 的精确文本 diff，以及每个 XLSX 的创建、刷新、删除、行变化和哈希。旧版只含 Markdown／TSV 的受管文件不会被批量改写；只有用户以同一目标发起刷新、审阅迁移变化并确认后，才升级为新的 Markdown＋XLSX 形式。

原始对话、未作答问题、`[遗留]`、研究中的推断和存在冲突的事实不会直接制成正式卡片。软件事实发生变化时，通常会建立带新版本范围的后继卡，而不是静默改变旧卡含义。

当前环境没有提供经过校验的受管配置时，Agent 只能在对话中讨论和预览候选，不能猜测保存路径。此 Skill 也不会上传媒体、导入 Markji、提交或推送 Git。

可用素材通常来自 `guide-learning` 已核验的理解或文章、`study-log` 中稳定的 `[要点]` 和 `[纠错]`，以及 `english-coach` 识别出的真实稳定语言问题。上游素材不携带制卡授权，用户仍需单独提出请求。完整组合方法见[学习类 Skill 组合使用指南](../learning-skills-user-guide.md)。
