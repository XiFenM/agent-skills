Guided Learning 帮助你真正理解一个主题：讲清机制和设计理由，连到真实系统，并能在陌生情境和面试中用自己的话讲出来。它适合概念、文档、论文、教程、示例和源码学习，也支持跨多次会话的课程。

## 讲解会讲到多深

每次讲解按五层深度组织，按你的目标决定讲到第几层：

1. **机制**：它是什么、怎样运作。
2. **设计理由**：它解决了什么核心矛盾，与替代方案相比换来了什么、付出了什么。
3. **真实系统**：对应的源码位置、关键配置和有代表性的真实数字，并注明来源和版本。
4. **边界**：什么时候不成立，瓶颈和失效方式在哪里。
5. **表达与迁移**：能在 60–90 秒内讲清，并用到没讲过的系统上。

目标是工程岗位或面试准备时，默认讲到第 5 层。讲解先给结论和机制，适用边界集中写一句，不在每段都附免责说明。小算例只用来让机制看得见，讲完会回到真实规模。配置中可以写明你的背景和目标深度，Agent 会把新内容与你熟悉的系统对照，已熟悉的部分不从头讲。

## 检查题考理解，不考计算

检查题要求你解释、预测、判断，而不是重复刚才的计算步骤，例如：

- 这个设计解决了什么？去掉它会坏在哪里？
- 改一个条件，结果会怎样变化？为什么？
- 从一个现象出发，原因可能在哪里？用什么证据区分？
- 两种方案在什么场景下各自更合适？
- 把刚学的模型用到一个没讲过的系统上。
- 用 60–90 秒向面试官讲清这个机制。

只有估算本身就是目标能力时（例如通信量或显存估算）才会出计算题，并且要求你解释数字的含义。题目有歧义属于出题问题：Agent 会澄清并换一道题，不把它算作你的错误。

## 节奏会跟着你调整

默认连讲两三个相关的节点再提一个问题。你连续答对时，节点会变大、题目会变难，复述类练习会省掉；答错时只补差的那一点，并换个条件再确认。你也可以直接说"讲快点""多讲少问""多出题"。

## 三种使用范围

| 范围 | 适用情况 | 默认行为 |
| --- | --- | --- |
| 一次答疑 | 只想解决当前问题 | 直接解释，可附一道检查题；不写任何文件 |
| 独立学习（Session） | 集中学习一个主题，之后可能继续 | 需要跨会话时，只保存会话事件和恢复位置 |
| 长期课程（Course） | 明确跨多次会话学习多个课次（Lesson） | 维护计划、每课的证据账本和唯一的恢复位置 |

已有课程记录不会把一次答疑自动升级为课程；关闭一课后也不会自动开始下一课。

## 一堂课怎样进行

1. **开课导入**：先用一段连贯的叙述说明背景和核心矛盾、将学会什么、路线和完成标准，并给出之后可以回看的全流程骨架。恢复已开始的课时只简短定位当前位置。
2. **核对前置**：先看已有记录；只有答案会改变讲解起点时才问你一个问题。"不知道"是有用的信息。
3. **逐节点讲解**：按五层深度讲，按上面的方式提问和调整节奏。
4. **导师串讲**：所有节点讲完后，Agent 亲自沿同一个贯穿案例把全流程串一遍，并落到真实规模。
5. **综合验收**：通常 2–4 题，覆盖整体模型、一个关键取舍、一个没讲过的迁移，并至少包含一道口述题。
6. **按证据决定是否练习**：证据已经充分就直接进入结课确认；仍缺实践或实验证据时，才安排最小的正式练习。

## 正式练习与结课

正式练习开始前，Agent 会一次说明：为什么做、你交付什么、怎样算通过、文件边界（你写／我维护／我只读／本次不动）、求助如何影响独立证据，以及非目标。你接受后才开始准备验收材料。约定有变化时，版本号加一并请你重新确认。

- **代码练习**：默认测试驱动。Agent 编写并核验验收测试，你实现核心逻辑，从可信的失败推进到通过。只有测试设计本身是学习目标时，才需要你写测试。
- **实验或 benchmark**：你在看到结果前预测方向和原因，结果出来后解释证据。实验方法与 harness 由 Agent 主导，包括预热、同步、重复次数、对照、指标和"支持／否定／证据不足"的判据；Agent 会说明设置思路，不会让你猜这些参数。只有实验设计本身是学习目标时，才由你负责这部分。
- **求助**：可以随时自然地要提示或完整示范。帮助透露了关键解法时，只需在受影响的范围换一个相近的新题重新验证，不用重学整课。

每个目标在开课时说明需要哪类证据：理解（讲清模型和设计理由，完成迁移或口述）、实践（完成并通过你负责的工件）、实证（事前预测、可复现的测量和对结论的解释）。结课时 Agent 会逐项列出证据和遗留事项，由你确认是否关闭。

## 记录写在哪里

学习状态只落在三处：**计划**（长期目标和候选课程）、**课程账本**（本课目标、证据和结课结论）、**断点**（唯一的"现在在哪、下一步做什么"）。当前是哪一课只由断点记录，其他文件不重复。普通讲解、追问和答对都不写文件；只在会话边界、练习约定、证据变化和结课时写，每条事实只写一处。

读取本地的图片、drawio 等混合资料时，Agent 会用专用的 `material_reader.py` 检查你明确选中的文件，不扫描整个学习目录；格式检查不代替实际看图。用法见[资料读取说明](../../skills/guide-learning/references/material-reading.md)。

## 你需要做什么

- 说明想理解的问题或想形成的能力；有指定的资料或版本时一并提供。
- 用自己的话回答检查题和口述题，完成正式练习中你负责的部分。
- 卡住时直接说需要什么程度的帮助；随时可以调整节奏、暂停、恢复或转向。
- 在开始新课、接受练习约定、改变目标范围、修改你负责的文件和结课这些位置作出确认。

## 与其他 Skill 的关系

`guide-learning` 不负责大范围搜索和治理资料、整理学习过程记录、保存原始对话、提供英语反馈或制卡；这些分别交给 `resource-planning`、`study-log`、`english-coach` 和 `memo-cards`，每次交接都由你确认。主题学完后，可以另外请求写一篇学习文章；文章需要确认素材、用途和目标文件，不改变课程状态。

完整的组合方法见[学习类 Skill 组合使用指南](../learning-skills-user-guide.md)。
