Guided Learning 用于带领用户理解一个主题，并通过主动回答、轻量应用和必要练习形成可以检查的学习证据。它适合概念、文档、论文、教程、示例和源码学习，也支持跨多次会话的课程。

## 三种使用范围

| 范围 | 适用情况 | 默认行为 |
| --- | --- | --- |
| 一次答疑 | 只想解决当前问题 | 直接解释，按需加入一次轻量检查，不建立课程或持久状态 |
| 独立学习（Session） | 希望集中学习一个主题，之后可能继续 | 目标位置明确并获授权后，在会话边界保存至多一条简短进展记录；有后续任务时再保留恢复位置 |
| 长期课程（Course） | 明确希望跨会话学习多个课次（Lesson） | 维护长期目标、已授权课次和逐目标掌握证据 |

已有课程记录不会自动把一次答疑升级为长期课程。长期课程一次只推进一个当前课次；关闭当前课次后，也不会自动开始下一课。

## 学习方法

1. **确定目标与起点。** Agent 根据用户的问题、已有材料、版本和既有证据判断起点。只有缺失信息会明显改变目标、范围、掌握标准或文件权限时，才会提出简短问题。
2. **建立全局图。** 先说明主题解决什么问题、包含哪些关键节点、节点之间如何关联，以及最终需要什么证据。
3. **逐个节点学习。** Agent 先讲清当前机制和边界，再邀请追问并提出一个基于已讲内容的理解检查。用户回答存在差距时，只补充当前缺口，然后换条件复查；理解无误时直接进入轻量复述、举例、映射或推导。
4. **综合验收。** 所有节点完成后，用户需要连接各节点，解释中心模型、关键边界，并处理一个没有直接讲过的相近情境。
5. **按证据决定是否练习。** 已有证据充分时跳过形式性的作业；仍缺实践、迁移或实验依据时，只安排能够补足缺口的最小正式练习。

Agent 不会要求用户猜测尚未教授且无法从已有知识推导的事实。“不知道”、一次答错、沉默或速度较慢都可以帮助调整教学起点，不会直接被判断为没有能力。

## 正式练习与掌握确认

正式练习开始前，Agent 会一次说明练习原因、用户交付内容、通过标准、文件所有权、求助对独立证据的影响，以及非目标和完成门槛。用户接受后才会准备验收材料或进入正式评审（Review）。

用户默认拥有并完成主要练习成果，Agent 维护测试、评分标准、fixture 或其他验收材料。代码练习默认采用测试驱动方式：契约接受后，Agent 先创建并核验最小验收测试，说明测试路径、运行方法和覆盖边界，再由用户完成核心实现并从可信的失败推进到通过。只有测试设计本身属于学习目标时，才要求用户编写测试。

实验或 benchmark 练习中，用户可以在看到结果前预测方向和原因，并在结果出现后解释证据。具体实验方法与 harness 默认由 Agent 主导，包括选择与结论相称的预热、同步、重复次数、运行顺序、控制变量、指标和“支持／否定／证据不足”判据；Agent 会说明设置思路，但不会要求用户猜出这些参数。只有实验设计本身属于学习目标时，才让用户负责这部分。Agent 也不会为了形式上的严谨自动增加统计检验、profiler 或大规模参数扫描。

用户可以自然地要求提示或完整示范；如果还需要 Agent 修改用户负责的文件，需要另行确认范围。如果帮助已经透露关键解法，只需要对受影响的范围换一个相近情境重新验证，不需要重学整个课次。

长期课程中的每个课次会根据目标预先声明需要哪些证据：

- **概念证据**：能够独立解释中心模型、关键边界并完成迁移。
- **实践证据**：完成用户拥有的练习成果，通过必要验收并解释重要验证。
- **实证证据**：用户先提出可检验的预测，Agent 建立明确、可复现且最低充分的测量方法，用户再说明
  结果支持、不支持什么以及适用范围。

并非每个目标都需要三种证据。到达完成门槛后，Agent 会展示证据和遗留事项，由用户决定是否关闭当前课次。

## 用户需要做什么

- 说明想理解的问题或希望形成的能力；有指定资料或版本时一并提供。
- 用自己的话回答理解检查，完成短复述、举例、推导或正式练习中的主要成果。
- 卡住时直接说明需要什么程度的帮助，也可以随时调整节奏、暂停、恢复或转向。
- 在目标范围、正式练习、文件所有权、掌握确认和下一课等会改变学习边界的位置作出选择。

## 来源、记录与可选产物

用户选择的资料可以作为教学主线，但不一定能够裁决所有事实。源码、官方文档、论文和本地实验分别只支持各自范围内的结论；遇到版本差异或来源冲突时，Agent 会说明边界并按需核验。

普通讲解和逐轮问答默认不反复写入文件。明确进行独立学习或长期课程时，只会在会话边界或耐久事实发生变化时，向已授权位置保存最小记录；每段实质进展至多记录一条简短事件，只有存在后续恢复任务时才保留恢复位置。主题已经完整时，可以另行请求学习文章；文章需要确认素材、用途和目标文件，也不会改变掌握状态。

`guide-learning` 不自动搜索并治理大批资料，不自动整理过程日志、保存原始对话、提供英语专项反馈或制作卡片。这些事项分别交给 `resource-planning`、`study-log`、`english-coach` 和 `memo-cards`，每次交接都由用户确认。

完整组合方法见[学习类 Skill 组合使用指南](../learning-skills-user-guide.md)。
