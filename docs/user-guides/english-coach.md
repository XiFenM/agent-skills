English Coach 用于两类英语学习：在真实交流中提供低打扰反馈，以及围绕已经学过的内容进行英语表达练习。它只处理语言表达，不代替主题教学，也不会把英语是否流利当作内容是否掌握的证据。

## 什么时候适合使用

- 用户本人正在用英语交流，希望顺便改善表达自然度、搭配或用词。
- 用户明确希望用英语回顾已经学过的技术或其他主题。
- 用户希望练习主动表达，而不是只阅读翻译或范文。

纯中文讨论不会触发英语反馈。代码、报错、引用、专有名词和 Agent 生成的英语也不会被当作用户的英语样本。用户可以随时用自然语言要求跳过反馈、增加解释、改用中文、暂停或停止。

## 交互如何进行

### 随行反馈

Agent 会先完成用户原本的学习、技术或工作请求，再决定是否补充一条有价值的英语反馈。默认只处理最影响含义或自然度的问题，并说明原表达、建议表达和简短原因。如果原表达已经自然，Agent 不会为了维持固定格式而强行纠错。

### 英语回顾

一次标准回顾约为 10–15 分钟，通常围绕几个已经学过的内容点展开：

1. Agent 先提供少量术语、词块或句型支架，不直接给出完整答案。
2. Agent 每次提出一个英语问题，用户先主动回答。
3. 影响含义的问题会及时纠正，轻微问题通常延后处理，避免每句话都被打断。
4. 用户卡住时，Agent 会从关键词或句首开始逐步增加帮助。即使给出完整示范，之后也会换一个条件再次练习，而不是把逐字复读当作掌握。
5. 最后完成一次综合表达或迁移表达，由用户先总结，Agent 再集中反馈。

完整翻译、中英对照和跟读范本都不是默认内容，用户需要时可以直接提出。

## 用户需要做什么

- 回顾开始时说明主题、材料和希望加强的表达方向。当前对话中的已学内容可以直接使用。
- 尽量先用英语主动回答；不知道如何表达时，可以改用中文说明卡点。
- 英语使原意不清楚时，补充说明自己原本想表达的内容。
- 如果需要读取历史学习材料、保存结果或制作卡片，确认相应的素材范围和后续交接。

## 结果与边界

普通反馈和英语回顾默认只保留在当前对话中，不创建日志、卡片或学习状态。历史会话的发现与提取交给 `study-log`；稳定且真实的语言问题如需制卡，交给 `memo-cards`；需要重新讲解、查证或验证主题内容时，交给 `guide-learning`。

语言评价与内容判断始终分开。内容正确但表达不自然时只纠正语言；发现高置信度的内容错误时，Agent 会单独说明，不会继续把错误结论作为英语范本。英语卡顿也不会修改课程记录、恢复位置或内容掌握状态。

需要把英语学习与其他学习流程连接起来时，参阅[学习类 Skill 组合使用指南](../learning-skills-user-guide.md)。
