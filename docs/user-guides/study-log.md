Study Log 用于从 Codex 或 Claude Code 会话中选择学习对话，并在学习仓库内保存精炼的结构化记录与一一配对的可追溯可见文本。两种产物用途不同，原文的隐私与披露范围仍需单独确认。

## 选择记录类型

| 类型 | 适用情况 | 保存内容 |
| --- | --- | --- |
| 结构化记录（`structured`） | 日后复盘、保留纠错、整理高价值问答或准备制卡素材 | 学习者原始回答、误解、纠错、关键转折、高价值问题和遗留事项 |
| 可追溯文本归档（`raw`） | 审计、研究或需要逐轮查看当时可见对话 | 带来源、边界和校验信息的“可追溯可见文本对话” |

正式导出以同一主题的一组文件为单位。只要候选或预览时不写文件；明确只要其中一种时按用户范围处理，并说明缺失的配对项，不把单份记录说成完整导出。

## 保存在哪里

例如结构化记录为 `推理框架/log/2026-09-15-topic.md`，对应原文固定为 `推理框架/log-raw/2026-09-15-topic.md`：同级目录、相同文件名，原文元数据绑定结构化路径。原文不放进结构化目录的子目录，避免被制卡或英语复习的递归素材清单纳入。

全部导出都在当次项目内；临时材料使用 `.study-log/scratch/` 并在用完后删除。旧的用户级私有归档目录只用于查找历史文件，不再决定新导出位置。保存不自动执行 Git stage、commit 或 push；内容进入仓库也不意味着获准公开。

## 共同流程

1. **确定来源。** 用户说明项目、客户端和目标会话。Agent 只发现当前任务相关的根会话，不查看无关会话。
2. **预览候选。** Agent 展示会话时间、消息数量、首尾内容、稳定消息边界和隐私风险类别。工具检测到的凭据和个人标识值会在预览中遮盖；检测并不穷尽所有风险，归档前仍需用户检查隐私和内容所有权。
3. **确认边界。** 用户选择需要保存的起止消息。存在多个会话或重复文本时，Agent 不会自行猜测。
4. **生成配对产物。** 先在仓库内临时提取材料，整理为简洁记录并清理临时文件；确认原文的来源、边界、状态、风险与目标后，由工具生成同名配对归档。
5. **核对与更新。** 工具验证配对路径、来源绑定、消息边界和内容完整性。已有结构化记录更新前展示差异；可继续追加（`partial`）的归档只能向后扩展，转为最终封存（`final`）后不再原地覆盖。

## 用户需要做什么

- 确认会话、主题和消息边界，以及结构化文件与配对原文的位置。
- 保存结构化记录时选择准确目标；已有同一记录时审阅差异。
- 保存可追溯文本时确认可继续追加或最终封存、仓库内位置和隐私处理方式。
- 对凭据、个人信息或可能的专有内容作出选择；所有权或适用政策不清楚时，不应继续归档。

用户只需使用自然语言说明这些选择，不需要记忆脚本命令。

## 结构化记录

结构化记录保留学习过程中具有复盘价值的差异，通常使用 `[要点]`、`[纠错]`、`[转折]`、`[高价值问题]` 和 `[遗留]`。它不会复写完整教学正文，也不是知识权威、课程状态或掌握证明。

如果没有本地原始会话，但当前可见对话已经足够，可以据此整理结构化候选并明确来源边界；不能伪造原文文件或宣称配对导出完成。

## 可追溯文本归档

这类产物只能准确称为“可追溯可见文本对话”。它默认排除 system、developer、reasoning、工具事件、客户端注入和附件正文，因此不是完整客户端会话，也不表示内容已经匿名化。

高置信度凭据默认阻止写入，也可以在明确选择后采用可复现脱敏；仓库内不允许原样保存凭据。可能的专有内容需要单独确认，并说明将来进入 Git 历史的风险。目录始终从已确认的结构化文件同名派生；不会自动修改 `.gitignore`。

## 迁移旧归档

迁移前展示原归档校验值、目标配对和消息范围；确认后由工具生成新文件，不手工改写逐轮正文。旧归档覆盖多个主题时可以拆分，同一主题跨归档时可以合并，但消息必须不丢失、不重复并保留来源。验证新文件后，才按用户的移动要求删除旧路径。

历史结构化记录已被卡片引用时，可以保留其字节原样，通过规范同名路径与原文绑定完成配对，避免无意引起卡片来源哈希变化。已有索引只在当前维护范围明确时更新，工具不自动创建索引；没有原文的历史记录不补造。

## 与其他 Skill 的边界

`study-log` 不修改课程状态、文章、卡片或 Git 历史。`guide-learning` 可以在暂停或结束处提议整理结构化记录，但得到用户同意后才会交接。`memo-cards` 可以使用稳定的 `[要点]` 和完整 `[纠错]`，不能直接使用 `[遗留]` 或可追溯文本对话。历史材料用于英语回顾时，由本 Skill 负责发现和选择会话，再由 `english-coach` 负责语言练习。

完整组合方法见[学习类 Skill 组合使用指南](../learning-skills-user-guide.md)。
