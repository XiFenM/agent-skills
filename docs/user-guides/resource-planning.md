Resource Planning 用于研究、比较和维护学习或工作资料组合。它把资料发现、来源刷新和组合决策分成三种独立模式，避免一次搜索直接改变长期计划。

## 三种使用模式

| 模式 | 适用情况 | 结果 |
| --- | --- | --- |
| 专题研究（`research`） | 围绕当前问题寻找、比较或推荐资料 | 默认在对话中给出研究结果；明确要求并确认预览后可保存研究简报（brief），但不会自动加入资料组合 |
| 来源刷新（`refresh`） | 增量检查已经配置的来源和查询 | 登记新证据与候选并生成不可变报告，不会批准候选或修改稳定资料组合 |
| 组合评审（`review`） | 评审已经登记且适合处理的候选 | 逐项决定采用、延后、拒绝、阻止、退役或标记为被取代，不进行广泛的新资料搜索 |

如果请求无法判断属于哪一种模式，Agent 会先用一句话确认。三种模式不会自动连续执行。

## 研究与决策方法

1. **明确问题和范围。** 包括目标读者或当前水平、技术与时间边界、截止点、成本限制和已有资料。
2. **收集直接证据。** 搜索摘要、榜单、star 数和“官方”标签只用于发现线索。Agent 会区分一手资料、工程观察、独立验证和教学材料，并核对它们各自能够支持的结论。
3. **先检查准入条件。** 资料身份、版本、一手锚点、关键结论、冲突和重复关系不清楚时，不进入价值排序。
4. **再比较实际价值。** 分别说明目标相关性、相对现有资料的信息增量、内容持久性，以及学习和维护成本，不使用一个缺少依据的总分代替判断。
5. **预览后再写入。** 研究简报、来源刷新报告、资料登记库（registry）和稳定资料组合的任何写入，都会先展示目标、状态变化和准确差异。组合评审中的每个决策项还需要用户逐项确认。

## 用户需要做什么

- 说明要解决的问题、范围、时间与成本限制，以及希望采用的模式。
- 检查候选资料的证据、冲突、不确定性和预期价值。
- 判断仅凭标题或语义相似而无法安全合并的可能重复项。
- 在保存研究简报、资料登记库、报告或稳定资料组合前确认本次准确预览。
- 对登录、付费访问、私有网络和 Git 操作分别授权；这些事项不包含在普通发布确认中。

## 结果与边界

专题研究默认保持纯对话和零写入。来源刷新会记录每个已配置来源或查询的覆盖结果，局部失败会明确标为阻塞，不会被表述为全局没有更新。组合评审只处理已登记候选，并且只修改预览中绑定的资料位置。

当前环境没有提供有效的受管配置时，只能进行主题驱动的对话式专题研究，不能猜测资料登记库、来源范围或保存目标。数量目标只用于控制一轮需要审阅的决策负担，零个合格候选也属于正常结果。

资料被加入稳定组合不等于已经开始学习，也不会修改课程记录、恢复位置或掌握状态。用户确认资料后，可以另行交给 `guide-learning` 开始教学；学习过程中出现广泛资料发现或长期资料治理需求时，也可以从 `guide-learning` 返回本 Skill。完整组合方法见[学习类 Skill 组合使用指南](../learning-skills-user-guide.md)。
