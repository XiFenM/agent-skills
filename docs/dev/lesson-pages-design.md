# lesson-pages 维护说明

本文给维护 `skills/lesson-pages` 的人看：模板怎样组成、改样式时要守住什么、怎样重建示例页并检查画面。
行为规则以 [SKILL.md](../../skills/lesson-pages/SKILL.md) 和它的参考文件为准，决策背景见
[D55](../learning-skills-review.md) 到 D60；以后可以挑的视觉与交互想法记在 [lesson-pages-ideas.md](lesson-pages-ideas.md)。

## 文件分工

| 文件 | 作用 |
| --- | --- |
| `assets/lesson-template.html` | 唯一的页面模板：内容安全策略、标记 meta、`#lp-boot`、`#lp-base`、`#lp-page-style`、页头、两个插入标记、符号表与来源、`#lp-runtime` |
| `assets/looks/*.css` | 蓝图、朱批两种风格的样式表；`new --look` 与 `look` 把选中的一份原样写进页面的 `<style id="lp-look">` |
| `assets/packs/<名字>.css`、`.js` | 十个部件包：海报 `poster`、对数尺 `scale`、误区对照 `myth`、类比卡 `analogy`、公式解剖 `anatomy`、逐行推导 `derive`、执行回放 `replay`、系统结构图 `zoom`、源码浏览器 `source-tree`、逐步时序图 `timeline`；页面用到 `lp-<名字>` 时才写进去 |
| `scripts/lesson_pages.py` | `new`、`add`、`continue`、`state`、`render`、`look`、`trace`、`check`、`outline`、`find`、`serve`；只用标准库 |
| `scripts/browser_checks.js` | 接受 Playwright Page 的本地页面检查函数；在隔离上下文检查长读数、窄组件、多行选项与正常动画滚动，不修改读者当前页面 |
| `scripts/render.cjs` | 写入时由 Node 运行：用 KaTeX 渲染 `.tex`，用 highlight.js 给 `pre.lp-code[data-lang]` 着色 |
| `assets/vendor/` | KaTeX 0.19.0 与 highlight.js 11.12.0 的发布文件，原样附带，许可与校验值见 `NOTICE.md` |
| `scripts/context_config.py` | 受管配置 `agent-skills.lesson-pages/v1` 的严格校验 |
| `references/*.md` | 按读取时机拆开的参考：`opening.md` 建页时，`page-structure.md` 每次写片段前，`upkeep.md` 恢复、结课、分页与改错时，`interactive-widgets.md`、`widget-packs.md`、`page-design.md`、`files-and-viewing.md` 用到时 |
| `references/example-*.html` | 开课、讲解、双栏源码浏览器和逐步时序的声明式片段；经 `new`／`add` 生成完整页面并要求零错误、零警告 |
| `tests/fixtures/widget-packs.html` | 每种部件包各一个的第 3 节，接在示例页后面；测试用它检查部件包的写入，回放轨迹与 `trace` 的结果逐行相同 |
| `references/sample-pages/*.html` | 第二轮试做定稿的成品页（2026-10-24 版）：同一课的讲义、蓝图、朱批三页，供人用浏览器看效果，Agent 不读进上下文。它们是快照，不随模板、风格或部件包更新，下一轮试做定稿后整体替换；测试只要求它们零错误 |

模板里的 `{{…}}` 槽位由 `new` 替换。页面里出现公式后，脚本在 `#lp-page-style` 之前写入 `<style id="lp-katex">`：
KaTeX 样式表、许可全文，以及按本页公式实际用到的字体（从 KaTeX 的字体规则推出，以 base64 内嵌；`.katex` 本身的
行高用 KaTeX_Main，所以它总在其中）；后来的公式用到新字体时只扩充这一块。块头记着 KaTeX 版本：版本变了，下一次写入
会先把全页公式按 `data-tex` 重新渲染，再换样式表，旧标记不会配上新样式。KaTeX 写进每个公式的 TeX 注记与 `data-tex`
不一致时，`check` 报 `math.stale`，`render` 会重排它；`render` 对没有变化的页面不升版本。`<!-- lp:content -->` 只在建页时使用，建页后删除；`<!-- lp:append -->` 是之后
每次追加的位置，每页恰好一个。选了蓝图或朱批的页面在 `<html>` 上带 `data-look`，紧跟 `#lp-base` 之后有一段 `#lp-look`；
讲义是模板本身的样子，两者都没有。`look` 切换风格时只改这两处并升一个版本，切回讲义后页面与原来只差版本号和日期。
页面用到某个部件包时，`#lp-look`（没有就是 `#lp-base`）之后有它的 `<style id="lp-pack-<名字>">`，`#lp-runtime` 之前有它的
`<script id="lp-pack-<名字>-js">`，都按名字排序；`new`、`add`、`state` 与 `render` 每次写入都重排这两组，用到的写进或刷新，
不再用到的删掉，所以已经齐全的页面写入前后这两组逐字不变。

`_place_hooks` 在部件组装之前，把正文中、boot之前或runtime之后的 `data-lp-hook` 移到运行时前；保留现有集中钩子顺序，再按源码顺序追加新钩子。
因此向一个节点 `add --into` 不会把不可见脚本留在图与批注之间。`check` 对正文钩子提示 `script.placement`，`render` 可修复，重复运行不再次改动。
基础运行时的布局修订 v3.1 保持 v3 接口：批注支持 `data-note-for`，默认跳过非内容／不可见锚点；选项背景跟随实际按钮的二维位置和尺寸；
对数尺按实际字体与组件空间拟合不可断行的读数，必要时转为纵向。

## 改模板时守住的约束

- 页面必须离线：内容安全策略为 `default-src 'none'`，只放行内联样式与脚本、同源与 `data:` 图片、`data:` 字体、同源
  连接（供本地服务的版本轮询）。`check` 要求页面中的策略与 `lesson_pages.py` 的 `CSP` 常量逐字相同，改策略时两处一起改。
- `#lp-boot`、`#lp-base`、`#lp-runtime` 是页面不能手改的三段。`check` 把页面里的这三段与当前模板比较，`#lp-katex`
  与按它记下的字体重新生成的结果比较，`#lp-look` 与对应的风格文件比较，不同时给出 `runtime.drift` 警告；旧页面不会被
  自动迁移，`#lp-look` 可以用 `look --to <当前风格>` 刷新。未知风格报 `look.unknown`，`data-look` 与 `#lp-look` 不成对报 `look.css`。
- 页面里没有 KaTeX 和 highlight.js 的脚本：渲染只发生在写入时。`render.cjs` 只放行 `\htmlClass` 的类名和
  `\htmlData` 的 `data-show` 步数，拒绝链接、内联样式和固定颜色（KaTeX 对不放行的命令只上错误色而不抛错，所以按
  输出里的颜色判断；错误色设成专用色值，连 `\phantom` 里和 MathML 副本里的也查得到）。片段在解析前统一为 LF，
  高亮结果再按页面的换行写回，避免孤立的 CR 让浏览器多出一行。
- 运行时的每个初始化步骤都包在 `try` 里，部件出错只在部件下显示一行提示；没有脚本时，所有内容（包括分步演示的
  每一步）都按顺序可读。
- 页面级动效各只做一次：封面升起、滚入视野时淡入（只给图、表、引用块、行间公式、补充和题目块；焦点先进了块就立刻显出；还没显出的块下错 18 像素，锚点停靠也多留 18 像素，显出后仍停在 24 像素）、骨架逐点画出、上次
  打开以来新通车的站散雾、导师划线与圈注、可调段落第一次读到时拨盘轻摆并浮出提示（6 秒后收起）、开放题标记轻闪三下、
  带锚点打开时目标亮起约 2.6 秒（只在从别处打开、或已打开的页面被外部链接带到别处时；页内链接、前进后退和普通刷新
  都不亮：历史记录上记 `lpSeen`、`lpInPage`、`lpSpotted`，因缺锚点重新加载时用 sessionStorage 的 `lesson-pages-spot`
  要求刷新后再亮，并且只有这时才把目标滚进屏幕（目标顶边在屏幕外、贴着顶边或贴近底边时），平常的跳转交给浏览器自己滚；都等滚动停稳再量位置；高的节圈它的标题，标题不在屏幕里就圈整节）；部件包里海报数字数一次并铺开格子、误解划掉一次、公式解剖的引线画一次。只有支持 IntersectionObserver 且未开启“减少动态效果”时，运行时才给根元素加 `lp-motion`，
  隐藏状态只在这个类下生效；打印前全部显示。不做自动循环；分步演示与执行回放的播放由读者按下，最后一步停止。
- 体积预算：模板不超过 170,000 字节，每个风格文件和每个部件包文件不超过 16,000 字节，由 `tests/test_learning_skills.py`
  检查。Agent 不读模板、风格文件和部件包，`new`、`look` 与写入命令直接复制它们。给 Agent 看的文档按读取时机分开算：
  `SKILL.md` 每次启用都加载，不超过 12,000 字节；`page-structure.md` 每次写片段前读，不超过 11,500 字节；其余参考到了
  用的时候才读，每份不超过 12,000 字节，不再给总和设上限，加按需读的内容不会挤占常驻部分。

## 风格

蓝图和朱批只改令牌和少量部件外观，结构、运行时和片段写法与讲义相同。风格文件的选择器都以 `:root[data-look="…"]` 开头：
浅色令牌写在它上面，深色令牌写在 `@media screen and (prefers-color-scheme: dark)` 里的
`:root[data-look="…"]:not([data-theme="light"])` 和 `:root[data-look="…"][data-theme="dark"]` 上，实验台的一组令牌在
`:root[data-look="…"] :is(.lp-stepper, …)` 上重新定义；`#lp-look` 排在 `#lp-base` 之后，同等优先级时它胜出。运行时只为
当前风格加东西（打印时两种风格各自换成浅色令牌，实验台也印成白底、浅底代码色）：朱批给节号加 `data-cn`（汉字节号）、在标题后加印章（取面包屑里的“第 N 课”），蓝图在标题栏加图号（页面
ID 大写）与版次（`R` 加版本号）。

## 部件包

部件包把只有部分页面用得到的部件留在模板之外。每个包是 `assets/packs/<名字>.css` 和同名的 `.js`，根类名是 `lp-<名字>`，
登记在 `lesson_pages.py` 的 `PACKS`。片段的写法与取舍写在 `references/widget-packs.md`，Agent 只读那一份。

- 写入：`_ensure_packs` 先删掉页面里认得的部件包块，再按页面当前用到的根类名重新写入，排在 `#lp-look` 或 `#lp-base`
  之后与 `#lp-runtime` 之前。
- 运行：包的脚本只把 `{ name, init }` 放进 `LessonPage.packs`。运行时的 `initPacks` 排在可调段落之后、符号互认与滚动
  出现之前，依次调用 `init(ui)`。`ui` 提供 `$all`、`failed`、`recovered`、`pop` 与 `unpop`（共用浮层）、`setNumber`、`announce`、
  `copyText`、`plainText`、`parseRanges`、`inView`、`reduceMotion` 和 `layout`（派发 `lp:layout`）。包不碰运行时的其他部分，
  出错时用 `ui.failed` 在部件下显示一行提示。运行时头注释写着版本，v3 起调用部件包。
- 检查：用到包却缺样式或脚本报 `pack.missing`；以 `lp-pack-` 开头却不是包的块报 `pack.unknown`；包的内容与资源文件
  不同报 `runtime.drift`，留着没用的包报 `pack.unused`，这两种运行 `render` 就能修好；页面用到部件包而 `#lp-runtime`
  早于 v3 时报 `pack.runtime`，这样的旧页面不会被迁移；部件的结构与 `references/widget-packs.md` 不符时报 `pack.markup`
  （例如回放某步的 `data-line` 不在代码里、`data-set` 不是“名字=值”、公式解剖的 `\tA`–`\tF` 与说明条数不等）。对数尺、类比卡、公式解剖、逐行推导、执行回放、系统结构图、源码浏览器与时序图都在
  `WIDGET_CLASSES` 里，开放题内外的泄题规则对它们生效。
- 外观：包的样式只用页面令牌；三种风格各自的差别写成 `:root[data-look="…"]` 规则放在包里，不放进风格文件。符号色只留给
  符号，包里用中性色与朱红。执行回放与系统结构图靠 `figure.is-stage` 上实验台，片段漏写时脚本补上。
- 公式解剖的 `\tA`–`\tF` 是 `render.cjs` 的宏，渲染成 `lp-t1`–`lp-t6`，`trust` 只放行这六个类名。
- 执行回放的轨迹用 `trace` 记录：它在单独的 `python -I` 进程里用 `sys.settrace` 运行例子，只记指定函数的行（推导式与
  生成器表达式的帧略过），同一行连续多次的事件合成一步（为内联的推导式；循环体若写在 `for` 行或 `while` 条件那一行，
  每一轮都只报这一行，整个循环会被合成一步，所以记到这样的行就拒绝，要求循环体另起一行），每次调用各自编号（CPython
  会复用帧的 id），第 2 次起每次调用的第一步标 `data-call`，回放到这里先清空变量表，输出每步改变的变量：浮点保留四位
  小数，小于 0.001 的用四位有效数字（不会显示成 0），负号写成 −，数组写成 `[a,b]`，值里没有空格。超过 30 秒或例子
  抛错时不输出。

加一个部件包：在 `assets/packs/` 放同名的 `.css` 与 `.js`，脚本照现有的包注册；把名字加进 `PACKS`，交互部件再加进
`WIDGET_CLASSES`；在测试的文件清单里登记，在 `tests/fixtures/widget-packs.html` 里放一个，写进 `references/widget-packs.md`，
再按下一节在三种风格下看一遍。

## 长课分页

一课主要按正文的阅读时间分页，文件大小只作后备。每个文件都要重复约 156–390 KB 的固定部分（模板约 156 KB，KaTeX 样式与
本页用到的字体，用到的部件包）；已批准的示例页有 493 KB，正文只读约 14 分钟。所以旧的“超过约 400 KB 就续页”
会让几乎每课讲完两段就拆，已经删掉；`page.size-soft` 改为 1.5 MiB，只提醒文件接近 2 MiB 的上限。

- 量法：`page_minutes` 用页面显示阅读时间的同一公式（中文每分钟 320 字、英文每分钟 180 词，不取整），只数 `main`
  的直接子块，不数符号表、来源、目录、`#part-prev`、`#next-part` 和顶层的样式与脚本（页头的分页目录不在 `main` 里）。
- 何时拆：只在 `add` 往一课最后一页末尾追加带 `.lp-node` 的片段、且这一页已有节点时判断。页面已到
  `SPLIT_DUE_MINUTES`（30）就拆，除非这一段讲完骨架剩下的站（此前各页的节点（本页的和分页目录里别页的）都没讲过的站还有，
  且这一段全讲到了；站早已讲全时不算），这时留在本页，免得只剩串讲和验收的短尾页；追加后会超过 `SPLIT_LIMIT_MINUTES`（45），或
  文件已到 `SPLIT_FILE_BYTES`（1 MiB）时一定拆。串讲、验收、练习、复查题、补充、参考要点和题目状态都不触发拆页。
  答疑页（`qa-…` 且没有 `#intro`）、已到第 9 页的课，以及文件名不是 `<ID>.html` 的旧第 1 页不拆（`new` 现在要求文件名
  就是 ID），这时 `add` 照常写入，输出的 `note` 说明为什么没有换页。
  30 分钟约是三到四个满段（一段不超过约 9 分钟），按页面公式算的 45 分钟实际学习约一小时；用户在 30–45、40–60、
  20–30 之间选了 30–45（2026-10-26）。
- 谁来拆：脚本判断，`add` 不写入并在错误里给出确切的改法；Agent 把同一条命令的 `add` 换成 `continue`。两条命令只有
  一条能成功：段落放得下时 `continue` 也拒绝。
- `continue` 先建 `<课 ID>-part<N>.html`（ID 为 `<课 ID>-part<N>`，最多 9 页），再像 `add` 一样给上一页末尾加 `#next-part`（“接第 N 页”，
  链到新一页的第一个节点，节点标题保留公式和代码）。新页：标题、面包屑、主线资料和语言取自第 1 页并加“第 N 页”，风格取自上一页；
  `#lp-page-style` 先照抄第 1 页的（夹在两行注释之间，下次续页时换成第 1 页当时的），再接上一页自己写的规则；`data-key` 新生成；开头 `#part-prev` 链回上一页，照抄第 1 页 `#fig-0` 的站列表和
  图注（去掉 `data-rev`）。符号条目和
  来源从写下它们的那一页取（副本带 `data-lp-copy`，不再被复制），所以在原处改正会传到以后的新页；这一段自己定义的符号
  不复制。往副本里补充会被拒绝并指向原页。片段样式里定义了这一段所用类名的一并带上（片段自带的不重复，副本也带
  `data-lp-copy`，只从原页复制），之后在续页上 `add` 和 `state --fragment` 的片段也照此补带（输出 `carried_styles`）；
  `data-lp-hook` 脚本不跨页。单独一段讲解超过 45 分钟时 `add` 和 `continue` 都拒绝，要求分段写。开头盖第 1 版、新段盖第 2 版，第一次打开就显示“本次新增”。
- 两个文件无法一起原子写入：`continue` 先把上一页加上链接后的结果完整检查一遍（含脚本语法，只放过指向新页的那条链接），不合格就什么都
  不写；片段往上一页的块里送内容时也先拒绝，让 Agent 先在那一页 `add`。新页写成而上一页的写入仍失败（例如页面在中途被改）
  时，错误里给出补救命令，不带 `--fragment` 的 `continue` 只补这条链接。
- 上一页的运行时与当前同代（`lesson-pages runtime v3`）时，`continue` 写链接时顺手换上模板当前的 `#lp-base`、`#lp-boot`、
  `#lp-runtime`，让它的骨架也读分页目录、页头写“本页约”；更早的页面不迁移，输出里的 `note` 说明它不会链到后面几页讲的站、页头仍写“全文约”。
- 一课的各页靠文件名和回链认：`<课 ID>-partN.html` 的标记 ID 同名、同目录有 `<课 ID>.html`、开头 `#part-prev` 的
  `rel="prev"` 链到第 N−1 页，才算第 N 页；改了名的副本（如 `attn-03 (1).html`）自成一页，不改真正各页的目录，`find`
  给它标 `misnamed`。`new` 拒绝这种 ID。各页的 ID、回链与目录条目只解析一次，按文件修改时间缓存；编码坏掉的页照样
  认作本课，写它时报在 `directory_stale` 里。
- 写入规则：有后续页的页面拒绝末尾追加，`--into`、`--after`、只往符号表或来源送条目的片段照常；节点、题目、补充、
  图、串讲、验收、练习、`recap` 这些对话会引用的 ID 在整课内唯一；片段里 `href="#X"` 指向别的页时改写成 `文件#X`
  并在输出里列出；`--into`、`--after`、`state` 的目标在别的页时，错误写明在哪一页。`check` 新增 `link.anchor`（链到另一个
  课程网页的锚点必须存在），`data-reveals` 可以指向前几页已关闭的题，`check --anchor` 指出锚点在哪一页。
- 查看：`outline` 对分了页的课多给 `lesson`（各页的 ID、块、题目状态、阅读时间和下一个节点、检查、验收编号），`find`
  给出 `lesson`、`part`，支持 `--lesson`，并按页序排列；`serve` 的目录列表也按页序。跨页查 ID 用解析后的元素，按文件的
  修改时间缓存，链接按浏览器的规则解析（去掉首尾空白、解百分号编码）。
- 分页目录：分了页以后每页页头 `.lp-meta` 下有脚本写的 `<nav class="lp-pager" id="lp-pager">`：一行上一页、“第 N 页，
  共 M 页”、下一页，下面一个默认收起的 `<details>` 按页列出节点、导师串讲与综合验收（节点带 `data-stages`，标题保留行内
  标记），当前页的条目链本页锚点，别的页链 `文件#id`。目录取自各页正文（按文件修改时间缓存），`add`、`continue` 写完
  一页就刷新其他各页的目录：只有目录真变了才写，照常检查但不升版本、不改“更新于”，因为只是导航变了；刷新不了的页
  列在输出的 `directory_stale` 里，对它运行 `render` 就会补上（`render` 刷新本页和其他各页的目录，只有目录变了时也不升版本）。手改节点标题后目录会
  落后，`check` 报 `pager.stale`。目录按 id 找（不依赖属性顺序），写进去时一并补上标题里公式要用的 KaTeX 字体；样式表
  早于分页目录的旧页面，目录块里自带一小段样式。打印时只留“第 N 页，共 M 页”那一行。所有页间链接都是同目录的相对
  链接，整个目录搬到别处照样能用；`check` 新增 `link.absolute`，拒绝只在本机有效的链接与资源地址（`file:`、盘符、以 `/`
  开头，包括 `//主机` 的网络路径）。
- 运行时：骨架、站牌和小地铁按页序把分页目录里别页的节点也算作讲过它们的站，链到那一页的节点；本页的节点链本页锚点。
  本页也讲某一站时链本页的节点。这样前几页、后几页讲过的站都能直接点过去，“见续篇”和续页开头的节点列表都不再需要；还没在任何一页讲到的站仍是
  “未开通”。页头改为“本页约 N 分钟”。目录、地层、“本次新增”、滚动位置都按页各算。
- 没有做的：只按文件大小或节点数拆；每个骨架阶段一页；串讲和验收单独一页；`add` 自动写到 Agent 没点名的文件；页面之间
  共用外部样式和脚本；课程总览页；运行时跨页读取（`file://` 下读不到别的文件）；事后搬动内容重新分页。

## 升级随附的渲染库

1. 用 `npm pack katex@<版本>` 和 `npm pack @highlightjs/cdn-assets@<版本>` 取得发布包，核对 npm 给出的完整性值，
   先在临时目录解包。
2. 只复制现在附带的那些文件（`katex.min.js`、`katex.min.css`、`fonts/*.woff2`、`LICENSE`；`highlight.min.js`、
   `LICENSE`），不带 woff、ttf、mjs 或源码。字体是 OFL 1.1：核对字体名表里的版权行与保留字体名，必要时更新
   `fonts/OFL.txt` 的抬头，并把 `KATEX_VERSION` 改成新版本。
3. 更新 `NOTICE.md` 的版本与完整性值、`tests/test_lesson_pages.py` 的 `VENDORED` 校验值；字体增减时同步
   `tests/test_learning_skills.py` 的文件清单。
4. 跑全部测试，按上一节重建示例页并查看。KaTeX 的字体规则若有变化，`_katex_faces` 会按新样式表推出字体，已有页面的
   `#lp-katex` 会得到 `runtime.drift` 警告。

## 源码浏览器与逐步时序

源码浏览器从一份嵌套提纲生成左右面板；节点id留在原目录项，职责与来源只维护一次。运行时定位只调整树容器滚动，
SVG辅助线依据当前可见元素的真实边界重画。版本、父子路径、起始节点归属由Python结构校验；具体源码真实性仍由作者核验。

时序图复用基础stepper，initPacks较晚注册onStep后主动渲染当前步。每步的完整快照必须保持相同参与者／槽位及显示名；
直接跳步或回退不继承上一状态。model与observed区分解释模型和实际轨迹，来源写在图注；结构错误时退回完整静态步骤。

维护时运行 `skills/lesson-pages/tests/test_layout_runtime.py`：这三个浏览器行为回归分别覆盖零尺寸批注锚点、换行选项背景、长读数与单位；
它们需要可用的playwright-cli和本地Chromium，否则明确skip。`scripts/browser_checks.js`可用于临时生成的长页，正常动画下滚动并停留；
自动几何结果之外，还需目视部件、测试跳步／选择、键盘、无脚本与打印。既有sample-pages仍是历史快照，不为模板更新批量改写。
