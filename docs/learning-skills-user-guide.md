这五个学习类 Skill 分别负责教学、英语表达、学习记录、记忆卡片和资料组合。它们可以在同一次学习中配合，但不是一条自动执行的流水线。每次交接都需要明确目的和最小素材范围，读取、保存、制卡和发布授权也不会传递给下一个 Skill。

## 五个 Skill 的分工

| Skill | 负责什么 | 什么时候使用 | 默认结果 |
| --- | --- | --- | --- |
| [`guide-learning`](user-guides/guide-learning.md) | 讲解、理解检查、练习、评审和掌握验证 | 用户希望学习、理解、继续或恢复一个主题 | 一次答疑保持零写入；明确的独立学习或长期课程在已授权位置保存最小进展，有后续任务时再保留恢复位置 |
| [`english-coach`](user-guides/english-coach.md) | 英语自然度反馈和已学内容的英语主动表达 | 用户本人使用英语，或明确要求英语练习与回顾 | 默认只在当前对话中反馈 |
| [`study-log`](user-guides/study-log.md) | 结构化学习过程记录或可追溯可见文本归档 | 用户要求整理、保存或归档学习对话 | 先选择记录类型、会话和边界；可追溯文本归档单独确认隐私与目标 |
| [`memo-cards`](user-guides/memo-cards.md) | 把成熟材料整理为 Markji 本地暂存卡 | 用户明确要求预览、创建、刷新或去重卡片 | 先预览，确认后保存；用户手动导入 Markji |
| [`resource-planning`](user-guides/resource-planning.md) | 研究、刷新和评审资料组合 | 用户需要寻找、比较或治理资料 | 专题研究默认只在对话中；任何持久写入都经过准确预览和确认 |

## 建议的组合关系

```text
resource-planning（按需准备或治理资料）
                │ 用户确认采用的资料
                ▼
guide-learning（教学主流程）
      ├─ 用户以英语表达时，可叠加 english-coach
      └─ 用户决定保存过程时，交给 study-log 生成结构化记录

guide-learning 的已核验要点或文章 ─────┐
study-log 结构化记录中的稳定条目 ──────┼─ 用户明确提出制卡 ─▶ memo-cards
english-coach 的稳定语言候选 ─────────┘

study-log 的可追溯文本归档：独立的审计／研究分支，不进入制卡流程
```

图中的连线只表示可以交接素材，不表示自动启动下一个 Skill。

## 一次完整学习可以怎样进行

1. **准备资料。** 已有合适材料时可以直接开始学习。需要广泛搜索、比较多个来源或维护长期资料组合时，先使用 `resource-planning`。资料被采用以后，仍由用户另行确认是否开始教学。
2. **进入教学。** 使用 `guide-learning` 明确目标和范围，完成全局理解、逐节点讲解、主动回答、综合验收，以及证据确实需要的正式练习。
3. **按需加入英语表达。** 用户在学习中使用英语时，`english-coach` 可以在主任务之后提供低打扰反馈；也可以在内容学完后，明确要求一次英语主动表达回顾。语言表现不会改变内容掌握状态。
4. **决定是否保存过程。** 暂停或结束时，可以让 `study-log` 生成结构化记录。只有审计或逐轮研究确有需要时，才选择隐私风险更高的可追溯文本归档，并单独确认边界和私有目标。
5. **整理长期复习材料。** 当结论已经稳定、可追溯且值得反复强化时，再明确要求 `memo-cards` 制卡。素材可以直接来自已核验的学习要点或文章、结构化学习记录，也可以来自稳定的英语表达候选，不需要先生成学习日志。用户先审阅候选和差异，确认后保存本地暂存文档，最后手动导入 Markji。

并非每次学习都需要完成五个步骤。一次简单答疑通常只需要 `guide-learning`；一次英语回顾可以只使用 `english-coach`；只想比较资料时也可以单独使用 `resource-planning`。

## 常见的返回路径

- `guide-learning` 发现需要广泛补充资料时，可以提议交给 `resource-planning`；资料确认后再返回教学。
- `english-coach` 发现高置信度内容错误时，交给 `guide-learning` 重新讲解或核验。英语卡顿本身不代表内容没有掌握。
- `study-log` 中的 `[遗留]`、未解决问题或不稳定结论需要回到 `guide-learning` 继续验证，不能直接制卡。
- 经用户确认的结构化学习记录可以作为 `english-coach` 的历史回顾材料；历史会话仍由 `study-log` 负责发现和选择。
- `memo-cards` 发现事实冲突、来源不足或版本范围不清楚时，保持阻止预览，再交回相应学习或研究流程。

## 用户需要确认的事项

- **学习范围。** 一次答疑、独立学习和长期课程的记录与完成标准不同。
- **Skill 交接。** 上一个 Skill 的建议或产物不会自动启动下一个 Skill。
- **素材边界。** 历史会话、结构化记录、文章和资料组合各有独立的读取范围。
- **写入和发布。** 配置中的可用路径不是当次授权。创建、覆盖、制卡、资料组合变更和可追溯文本归档分别确认。
- **外部操作。** Markji 导入、付费或私有访问、Git stage、commit 和 push 不包含在普通保存确认中。

## 可以直接这样表达需求

用户不需要记住固定命令，也不一定要说出 Skill 名称。例如：

- “请比较这三份教程，说明哪一份适合我当前的基础。”
- “请沿这篇论文带我学习，先建立全局图，再逐步检查理解。”
- “接下来请用英语回顾刚才学过的三个内容点。”
- “把今天这段对话整理成结构化学习记录，先让我确认会话边界。”
- “把这些已经核验的要点制作成墨墨卡片，先预览，不要直接保存。”
- “把这段可见对话作研究归档，请先检查隐私风险并确认保存范围。”

用户也可以随时自然说明暂停、继续、调整节奏、减少反馈、改用中文或停止当前流程。
