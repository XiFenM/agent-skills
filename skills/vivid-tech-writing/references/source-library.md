# 样板库：按“偷一个动作”来读

这不是“必读书单”，是“样板库”。

读法只有一条：**不要问“这本书好不好”，要问“这一页他做了什么动作，我能搬到哪里”。**

一次只偷一个动作。偷完，写 200 字仿写。一周后回看，它有没有变成你的肌肉记忆。

> 链接说明：英文书尽量链到免费全文/作者页；中文书有些链到书评或摘录，因为官方页经常失效；视频用 YouTube 频道或 B 站搜索页。链接会失效，优先按书名/频道名搜索。

## 如果只选五个

1. **看尺度**：Bryson《万物简史》开篇（把 650,000 小时变成“你”）。
2. **看压缩**：Feynman 第一卷第一章（一句话装下原子论）。
3. **看中文节奏**：曹天元《上帝掷骰子吗》第一章（把物理史写成帝国兴衰）。
4. **看交互解释**：Bartosz 的 *Gears*（让读者先拖滑块，再给术语）。
5. **看视频节奏**：3Blue1Brown 的 *Essence of Calculus* 系列（一个动画只讲一个变化）。

## 写给孩子的（5 本）

童书作家每天面对“注意力最短、最诚实”的读者：听不懂就走，无聊就合上书。童书里的手艺，比大多数写作课都硬。

| 作品 | 为什么值得学 | 偷一个动作 | 入口 |
|---|---|---|---|
| 乔安娜·柯尔 / 布鲁斯·迪根《神奇校车》 | 把知识变成任务：卷毛老师带学生进入现场。 | 给文章设计一个“任务”，让知识成为任务的副产品。 | [背景](https://en.wikipedia.org/wiki/The_Magic_School_Bus) |
| 尼克·阿诺德《可怕的科学》 | 用“恶心/危险/搞笑”制造记忆点，第二人称。 | 找一个“反常识的恶心细节”，但它必须是真的。 | [官方系列页](https://shop.scholastic.co.uk/horrible-science) |
| 大卫·麦考利《DK 万物运转的秘密》 | 猛犸象角色贯穿全书，剖面图讲原理。 | 设计一个重复出现的角色/物件，做读者的向导。 | [作者背景](https://en.wikipedia.org/wiki/David_Macaulay) |
| 汉斯·马格努斯·恩岑斯伯格《数字魔鬼》 | 用梦境叙事讲数学：每场梦一个概念。 | 把抽象概念写成一个“梦里的场景”。 | [背景](https://en.wikipedia.org/wiki/The_Number_Devil) |

## 怎么用这个库

1. **不要按顺序读。** 按手头要写的题目，挑 2 个样板：一个学结构，一个学句子。
2. **一次只偷一个动作。** 读完立刻写 200 字仿写，不许抄内容，只抄动作。
3. **一周后回看。** 如果那个动作没有出现在新文章里，说明只是“读过”，没有“学会”。

给用户推荐时，最多给 3 个，并说明“你现在这个问题，先看哪一个动作”。不要甩一个 50 本书的书单。
