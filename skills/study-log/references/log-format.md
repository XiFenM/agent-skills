# 学习记录 · 格式规范

> 输出位置：`{module}/log/YYYY-MM-DD-<主题slug>.md`。一次学习会话（或其某个主题）一份；同天同主题重跑覆盖重写。

## 文件骨架

```markdown
# 学习记录 · YYYY-MM-DD — <主题一句话>

> 来源：AI 会话 <客户端>:<id前缀>（HH:MM–HH:MM）· 模块：<模块名> · 关联产出：[<文章名>](<相对路径>)

## 问答与要点

- [要点] <问题式表述>？——<2–4 句要点>。（来源：<文章/资料 §节号>）
- [纠错] 场景：<当时在讨论什么>。我说「<错误表述>」→ 正确：<正确表述>。为什么：<一句原因>。
- ...

## 遗留问题

- [遗留] <问题一句话>（已挂账：<文章 §后续预告 / 进度.md / 学习断点.md>）
```

## 条目规则

- **一条一个点**（原子化，直接对齐 memo-cards 的原子卡要求）。多点讲解拆成多条。
- `[要点]` 用**问题式表述**开头——写成面试官能问出口的问题，后接可背诵要点；有边界/反例带上。
- `[纠错]` 必须含**场景**（当时想说什么）和**为什么**（原理性原因），与 `英语/log/` 的纠错条目同构；"我怎么错的"原话保留，别美化。
- `[遗留]` 只登记 + 指明挂账位置，不展开——展开是下次学习的事。
- 保留我的原话风格和思考过程，不写成教科书摘要；日期绝对；来源锚点用相对路径。

## 与其他记录的分工

| 记录 | 管什么 |
|---|---|
| 文章（`{module}/深入学习理解…/N-*.md`） | 学习的**结果**：成体系的叙述 |
| 学习记录（`{module}/log/`） | 学习的**过程**：问答、纠错、原始思考 |
| `进度.md` 📅 日志 | 一行式**账目**：日期/时长/学了什么 |
| `英语/log/` | 英语表达纠错（english-coach 辖区，不混写） |
