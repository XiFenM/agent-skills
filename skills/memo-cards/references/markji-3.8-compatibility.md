- 最低适配客户端：Markji `3.8.00`。
- 内容语法查阅日期：2026-08-11；表格导入客户端核对日期：2026-08-15。
- 2026-09-08 增量核验：[官方开放 API 与制卡指南](https://open.maimemo.com/#/)及其
  [OpenAPI 规范](https://open.maimemo.com/api_bundle.yaml)；用户指定的
  [AI 制卡注意文档](https://tutuji333.github.io/markji-faq/questions/content/card-syntax-guide/)补充当前客户端观察。
  后者对行内公式、公式选择题和公式挖空的描述属于较新能力，不把旧 PDF 的限制当作当前产品的完整能力。
- 官方入口：[墨墨记忆卡帮助文档索引](https://maimemo.feishu.cn/docx/doxcnkxpR2GA8Nrn3r0ApzkYmgM)。
- 批量制卡帮助：[墨墨记忆卡批量制卡使用帮助](https://maimemo.feishu.cn/docx/Aj55dnG0vooWktxMhnDc3JhonfQ)。
- 辅助官方链接示例：[墨墨论坛的公开链接语法页面](https://markji.discourse.group/t/topic/662)。
- 原始语法参考：[随 Skill 固定保存的用户提供 PDF](markji-content-syntax.pdf)，SHA-256
  `57438a84a630ab9f8897bed53cedb8899b09a55b816c09edc480eeed96a88201`。它固定本次核验所用的文档
  快照；外部在线说明仍可能更新。

这份参考只描述已验证的适配边界，不替代官方文档，也不把内容语法误当作表格导入协议。

当前网页端批量制卡入口接受 `.csv`、`.xls` 与 `.xlsx`，并只读取工作簿的第一个 sheet；一次导入使用一套
模板。因此本 Skill 为每个模板生成一个独立 `.xlsx`，首个且唯一 sheet 固定为 `cards`，表头严格等于
模板占位字段。用户仍应优先以 Markji 当前页面“下载模板表格”的字段名核对自定义模板，并在对应模板下
逐个上传。明确要求直接上传时，按[官方 API 流程](markji-api-upload.md)编译完整卡片内容。

## 支持面

- `---` 答案线；
- `[T#...#...]` 行内样式与 `[P#...#...]` 整行样式；
- 3.8.00 起支持的 `[Choice#ans/...#...]`；
- `[E##...]` KaTeX 公式；
- 用户明确提供的公共 HTTP(S) 链接；
- 可选 `[F#1#...]` 挖空，使用从 1 开始的分组编号，不作为默认生成方式；
- `choice-multi` 生成包含多个正确选项的 `[Choice#multi#...]` 块；
- 仅使用用户明确提供，或按当次授权从官方响应／回执核实的既有 Markji ID 生成 Audio、图片或卡片引用。

本地制卡不主动枚举远端媒体或关联卡，也不自动建立跨卡引用。公式、链接和媒体／卡片引用必须通过
request 中的结构化 content part 提供，由工具生成语法；不要把原始 Markji 标记混入普通文本。

历史 PDF 的基础约束仍适用于本工具：`T` 与 `F` 不支持跨行，`F` 不能嵌套重点标记；`P` 是整行
样式；`Choice` 的题干位于选择块外、选项逐行且 3.8.00+ 可用 `ans` 直接指定答案；`E` 是整行 KaTeX
公式，`Pic` 也是整行元素。`Choice` 选项可含重点标记但不能含挖空，颜色代码必须小写，`up` 与
`down` 不能并用。本工具目前只开放整行公式，未开放行内公式、公式选项或公式挖空；这是实现范围，
不代表新版客户端不支持。整行元素必须独占工具生成的渲染行。完整的版式约束与受控生成
规则见[卡片内容与版式](card-content-layout.md)。

工具还根据 registry 判断每个占位符是否独占模板一行。只有独占行的 content 字段可以生成多行 blocks
或整行 `E`／`Pic`；外层已有 Markji 语法或行前缀的字段保持纯文本，防止合法片段组合成非法嵌套。

## 保守校验

普通数据字段保持单行文本；普通 `[`／`]` 由渲染器变为 `\[`／`\]`，身份和事实文本保留原字符。
继续拒绝 `---`、代码围栏及原始 `[T#`、`[F#`、`[Choice#`、`[P#`、`[Audio#`、`[Card#`、`[Pic#`、
`[E#` 等语法注入，不用全角字符替换实际内容。公式只接收不带 `$`、`$$`、`\(...\)`、`\[...\]`
外层定界符的 KaTeX；需要方括号时用 `\lbrack`／`\rbrack`，避免碰撞 Markji 结束符。

URL 位于参数区；裸 `#`、逗号、引号、反斜杠、中括号和空白会被拒绝。先取得语义正确的编码 URL，
不能为了通过校验自动把片段标识等 URL 结构改成路径字符。媒体 `file.id` 保留大小写；音频默认显式
生成 `M` 手动播放。卡片引用参数的 `ids` 必须是真实 `root_id`，最多 5 个，保持顺序去重。

registry `1.1.0` 修正挖空及音频行为，并增加多选模板。原 2／3／4 选项模板只接受一个答案字母；
XLSX 继续使用已验证的 `ans` 模板，API 编译为官方指南的 `*`／`-` 选项格式，固定其顺序。
已有受管文件的模板升级会显示在下次精确目标刷新中，不自动批量迁移。

工作簿只使用 inline string 单元格，不写公式、共享字符串、宏、外部关系或额外 sheet。即使字段以
`=`、`+`、`-`、`@` 开头，也作为字面文本保存。工具验证固定 OOXML package、字段顺序、矩形行、
XML 合法字符、Excel 行列与 32767 UTF-16 code units 的保守单元格长度限制；Markdown manifest 再
绑定逐行摘要和完整 XLSX SHA-256。

链接只接受无凭据、非 localhost、非私有／保留 IP 主机的 `http` 或 `https` URL。KaTeX、ID 与显示文本也分别校验。模板中的固定样式由唯一 registry 提供，数据行不重复维护样式。
