# Markji 3.8 精简兼容面

## 证据与版本

- 最低适配客户端：Markji `3.8.00`。
- 查阅日期：2026-08-11。
- 官方入口：[墨墨记忆卡帮助文档索引](https://maimemo.feishu.cn/docx/doxcnkxpR2GA8Nrn3r0ApzkYmgM)。
- 辅助官方链接示例：[墨墨论坛的公开链接语法页面](https://markji.discourse.group/t/topic/662)。
- 实施时核对了用户本地保存的官方内容语法 Markdown；同目录配套 PDF 与 Markdown 原文均不随本 Skill 分发。

这份参考只描述已验证的适配边界，不替代官方文档，也不把内容语法误当作表格导入协议。

## 支持面

- `---` 答案线；
- `[T#...#...]` 行内样式与 `[P#...#...]` 整行样式；
- 3.8.00 起支持的 `[Choice#ans/...#...]`；
- `[E##...]` KaTeX 公式；
- 用户明确提供的公共 HTTP(S) 链接；
- 可选 `[F##...]` 挖空，但不作为默认生成方式；
- 仅在用户明确提供既有 Markji ID 时生成 Audio、图片或卡片引用。

本 Skill 不上传媒体、不发现 ID、不自动建立跨卡引用。公式、链接和媒体／卡片引用必须通过 request 中的结构化 content part 提供，由工具生成语法；不要把原始 Markji 标记混入普通文本。

## 保守校验

官方内容语法没有给出通用 TSV 转义合同。因此普通数据字段必须是单行、无 tab 的文本，并拒绝裸 `]`、
`---`、代码围栏及 `[T#`、`[F#`、`[Choice#`、`[P#`、`[Audio#`、`[Card#`、`[Pic#`、`[E#` 等保留语法
碰撞。无法证明安全时停止，不猜测转义。

链接只接受无凭据、非 localhost、非私有／保留 IP 主机的 `http` 或 `https` URL。KaTeX、ID 与显示文本也分别校验。模板中的固定样式由唯一 registry 提供，数据行不重复维护样式。
