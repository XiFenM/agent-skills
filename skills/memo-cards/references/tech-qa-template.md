# 技术Q&A卡 · 墨墨表格导入模板

> 用法与 [英语/cards/_templates.md](../../../../英语/cards/_templates.md) 的三卡型相同：把「模板」整段粘到墨墨「表格导入」左侧面板（`{{}}` 会标绿）→ 下载表格 → 把 TSV 数据行粘进去 → 上传导入。
> 素材源：各模块文章的〔面试问题Q&A〕节、`进度.md` 遗留问题、自测题库条目。
> **TSV 列顺序必须和模板里 `{{}}` 出现的顺序一致。**

## 技术Q&A卡

正面一个面试官能直接问出口的问题，背面是可背诵的要点 + 回忆锚点 + 出处。

**模板**（粘到墨墨左侧面板）：

```
[P#H1#{{问题}}]
---
{{答案}}
💡 [T#B,!36b59d#{{锚点}}]
📍 [T#!939393#{{来源}}]
```

**列顺序**：`问题 → 答案 → 锚点 → 来源`

**TSV 示例**：

```tsv
问题	答案	锚点	来源
autograd 为什么对新后端"免费"？边界在哪？	反向公式写成 device 无关的 aten 算子组合，反向执行时 redispatch 回后端已注册的前向 kernel——前向注册全了，反向自动可用。边界：fused kernel / 外部库算子没有 aten 分解，必须自己提供 backward。	backward = aten 组合 + redispatch	1-Internal-Overview.md §3
view 和原 tensor 共享什么、不共享什么？	共享同一个 Storage（数据零拷贝），不共享 TensorImpl——各自持有独立的 size/stride/offset 元数据。改 stride/offset 即可实现 transpose/切片。	多个 TensorImpl → 一个 Storage	1-Internal-Overview.md §1
```

**字段约定**：

- **问题**：一句话，面试官视角，能直接问出口。
- **答案**：2–4 句可背诵要点；有边界条件/反例的带上，别搬文章原文。
- **锚点**：一行代码 / 公式 / 关键词短语，作回忆钩子。
- **来源**：文件名 + 节号（如 `1-Internal-Overview.md §2.2`），方便回查原文。

**通用约定**（同英语卡）：样式只在模板里，数据行纯文本；颜色码小写（墨墨绿 `36b59d`、灰 `939393`）；TSV 别手动加引号。
