# 按需读取与校验学习资料

在实际需要读取本地混合资料，或确认某份资料的文件类型与格式时使用。更新 Skill 不运行本工具；
一次普通文本答疑也不需要先做整库检查。

## 精确选择与调用

先依据当前任务选定最小文件集合，使用 Skill 自带的 `scripts/material_reader.py`。以下从消费仓库根目录
运行，以 Codex 生成入口为例；其他宿主替换为实际 Skill 脚本路径：

```bash
python .agents/skills/guide-learning/scripts/material_reader.py --repo . \
  --path "notes/request-lifecycle.md" \
  --path "notes/request-journey.png" \
  --path "notes/request-journey.drawio"
```

`--repo` 指向消费仓库；所有 `--path` 都相对于该仓库。路径必须是精确
文件，不接受目录、glob、越界或符号链接。全部选中路径先通过安全预检，才开始读取正文。

- 默认只输出 JSON 检查报告，不输出资料正文或图片字节；需要选中文本的正文时添加 `--include-text`。
- 不扫描 collection、不展开相邻文件或 Markdown 链接、不联网、不写入文件或学习状态。
- 可检查用户本轮明确指定的未跟踪文件，但这不把它加入受管 allowlist。配置路径本身不是读取授权。
- 上限为 64 个文件、每文件 8 MiB、每批次 32 MiB；正文输出至多 256 KiB、JSON 至多 1 MiB。
  超限明确失败，不输出截断正文；缩小所选文件集合或换适用工具，不修改原资料来制造成功。
- 当前安全访问实现需要 POSIX 的 no-follow 与目录相对文件操作；不具备这些能力时明确停止，
  不静默降级符号链接保护。其他平台按原任务选用安全的本地读取工具，不影响 Skill 更新。
- 退出码 `0` 表示所选文件通过本工具声明的检查，`1` 表示报告中有格式错误，`2` 表示参数、路径或
  资源限制错误。格式错误不会阻止同批次其他合法文件给出报告；路径预检失败则不读取任何正文。

## 类型与结论边界

| 类型 | 检查范围 | 下一步 |
| --- | --- | --- |
| 文本、Markdown、源码 | UTF-8 解码及文本检查；可在输出上限内返回正文 | 默认元数据报告不代表已阅读正文，技术结论仍须按固定来源核验 |
| PNG | 文件签名、块结构与 CRC；不解码像素 | 使用图片查看工具实际看图，不能仅凭尺寸或校验通过评价图中理解 |
| drawio | XML 语法与根元素；拒绝 DTD／实体声明，不解压内嵌 diagram | 结合用户提供的导出图或适用绘图工具审阅；外层 XML 有效不保证内部图正确 |
| 其他二进制格式 | 明确报告不支持，不假装是 UTF-8 文本 | 按任务选择相应图片、PDF 等工具，不扩大到未选择的材料 |

以报告中的校验层次为准。格式通过不代表资料可信、技术结论正确、学习者已掌握，也不构成保存、制卡
或课程状态更新的授权。遇到格式错误或不支持的类型，说明具体文件与限制；与任务无关的坏文件不应
阻止更新 Skill 或阅读其他已明确选择的资料。
