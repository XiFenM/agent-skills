# Review loop：回忆地图、费曼微口述与跨周回捞

本参考用于学完之后的巩固与口头表达训练，解决“过一段时间就忘”和“心里懂但用自己的话说不出”。三项动作均由学习者按需触发，不是结课自动副作用，也不写入课程账本、断点或掌握结论。

## 1. 一页回忆地图（Recall Map）

结课或复习旧课时，按学习者请求把单个主题浓缩成**一屏大白话骨架**（写入仓库约定的复习地图 Markdown，或先在对话预览），与重型课程网页、审计日志职责分离。

固定 4 块，**硬限约 20 行**（绝不写成第二份教材）：

1. **自测口令（1 句）**：放在折叠块外，打开文件先看这句，在脑中顺一遍主线再展开对照。
2. **一句话主矛盾（20–35 字）**：这课到底在解决什么工程麻烦。
3. **主线 4–6 步因果链**：沿同一个主角或请求从头走到尾，一行一步，说人话。
4. **核心辨析（最多 3 条）与个人真实踩坑（1–2 条）**：面试高频分叉点，加上学习者真实踩过的坑。

约束：
- 正文默认放进 `<details>` 折叠块，方便打开即遮挡自测；卡面与正文不放 commit 哈希，也不堆防御性免责套话。
- 若学习者同时使用 `memo-cards`，本页骨架可直接作为该单元第 0 张“总览地图卡”的同一份源文本。

## 2. 随时 5 分钟费曼微口述

由学习者随时单点发起（例如“来 5 分钟微口述”“练一下 PD 搬家”），**不强绑在开新课前**，避免环境不方便说话时造成心理负担。支持并鼓励语音转文字直接盲讲，容忍同音错字，不打断表达流。

固定 4 步、**最多 3 个来回、5–8 分钟必收工**，绝不拖成新课：

| 阶段 | 谁做 | 动作 | 硬边界 |
| --- | --- | --- | --- |
| 第 0 分钟 | Agent 出题 | 抛 1 道面试官真实场景题，写明听众与 60–90 秒时长 | 题面不超过 3 句，不考背定义 |
| 第 1–2 分钟 | 学习者盲讲 | 脱稿一口气用大白话讲完，忘了精确字段名用土话顶上 | 不查笔记，不断流优先 |
| 第 3 分钟 | Agent 体检与追问 | 1 屏内给 3 项：① 讲顺了哪块（1 句）；② 最多 2 条跳步或混淆点加 1 句人话补丁；③ 顺着薄弱处抛 1–2 个改条件追问 | 先立后破，不展开长篇讲课 |
| 第 4–5 分钟 | 学习者接招与重讲 | 回答追问，再把刚才卡壳的那小段用顺口的话重讲 30 秒 → 确认过关即收工 | 3 个来回结束，不无限延展 |

默认**零写入**，不生成新日志、不修改学习断点。若学习者把某段讲出了特别顺口的比喻或三段式结构，可提议顺手反哺到对应回忆地图；若暴露出反复踩的真误区，留作后续按需制卡素材。

## 3. 跨周交错回捞

只靠单模块连刷容易“学新忘旧”。在仓库复习地图入口维护一张极简 **4 列回捞表**（单元、上次微口述日期、状态、下次重点盯不超过 15 字）：

- 抽题优先级：`⬜ 未练` 优先于 `🟡 卡壳`（3–5 天后再抽）优先于 `🟢 顺口`（14–21 天后再抽）。
- 学习者未指定微口述主题时，优先按回捞表挑 1 个最久未练或标 `🟡` 的旧单元；周末或集中复习时，可选 2 个跨周主题做 25 分钟串讲，把前后机制连成一张网。
- 回捞表只是复习调度提示，不替代课程账本或掌握度证据；更新回捞表需沿用仓库已有复习目录约定或当次确认。
