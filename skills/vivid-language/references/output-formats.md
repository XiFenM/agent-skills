# 交付格式：五种模式怎么把结果交出去

交付也是语言。先给一句"结果是什么"，再给展开；不要把过程放在最前面。

## diagnose

1. **一句话判断**：最要命的 1 个问题。
2. **诊断表**：病灶 / 原文证据（引一句）/ 手术。
3. **三个优先动作**：先改哪三处，为什么。
4. 最后问："要我直接改写吗？"

## rewrite

1. **改写**：全文或指定段落。
2. **改了什么**：3–5 条，对应到具体动作（如"去掉 7 处名词化""把开头从定义换成场景"）。
3. **待核实**：列出需要用户确认的事实、数字、引文。
4. 可选：给一个不同风格的开头（A/B），让用户选。

## draft

1. **Brief**：读者、承诺、入口、约束（5 行以内）。
2. **结构**：每节一句话。
3. **初稿**。
4. **待核实**。

## video

1. **一句话承诺**。
2. **口播稿**（按三句一节分段）。
3. **镜头表**（时间 / 画面 / 口播 / 屏幕字），模板见 [../assets/video-shot-sheet.md](../assets/video-shot-sheet.md)。
4. **待核实**。

## coach

1. 一个概念（不超过 200 字）。
2. 一个真实样板（引最短的必要片段 + 拆一个动作）。
3. 一个 10 分钟练习。
4. 请用户交作业，按"动作是否用对"反馈，不打文风分。
