## 1. 页面放在哪里

按顺序找，找到就停：

1. 生成副本 `.agent-skills-context.json` 中的 `page_targets`。有多个时按课程选；仍有歧义就请学习者选一个。存在
   这份 context 时，脚本只允许在这些目录里建页和写入；context 损坏或身份不符时脚本拒绝写入，请用户重新 materialize。
2. 这门课所在目录里已有的课程网页：用 `find --in <课程目录>` 查找。`find` 只查给定目录，不扫整个仓库。
3. 学习者指定的目录。
4. 都没有时，提议一个与课程账本、断点平级的新目录，例如 `<课程目录>/pages/`。

页面不放进 `guide-learning` 映射的计划、账本、断点或文章目录之内（受管配置会拒绝写入目录重叠），不放进 `.git`、
`.agents`、`.claude`、`.agent-skills*` 或嵌套仓库，脚本会拒绝这些位置和符号链接。

## 2. 文件名与拆页

`--page` 始终传相对 `--repo` 的路径；对话里的绝对文件链接不直接作为这个参数。解释器用当前环境可用的 `python` 或 `python3`。

- 文件名就是页面 ID 加 `.html`。Lesson 用账本 ID，独立 Session 用主题短名；ID 只用小写字母、数字和连字符，
  账本 ID 不符合或以 `-part2`–`-part9` 结尾（留给续页）时换一种写法，并在开课确认里写出。
- 同一个 ID 只有一个页面：恢复时直接按位置和 ID 找到它，用 `outline` 看内容，`add`、`state` 都要带 `--id` 核对。
- 很长的课分成几页：续页是同目录的 `<ID>-part<N>.html`，随本课的授权写入，页面之间用相对链接；见
  [upkeep.md](upkeep.md) 第 3 节。
- 学习者要的答疑页用 `qa-<主题短名>` 作 ID，路径确认后只写这一页。

## 3. 授权

- 第一次在某个目录建页前，说明路径和用途并取得确认。Lesson 把它并入 `guide-learning` 的开课确认，一次确认同时
  覆盖开课、页面路径和查看方式；独立 Session 在第一次写页面时确认；答疑页随学习者的请求确认路径。
- 确认后，本课页面的追加、题目状态更新和验证自动进行，不逐次询问。新的一课要建新页时，随下一课的开课确认一起
  说明。
- 学习者画像里的页面偏好只让 Agent 默认提出用页面，不是跨课的写入授权。受管配置与 allowlist 只给位置和上限。
- 从不自动进行：覆盖已有文件、修改别的课或学习者自己的页面、启动常驻服务、把页面发布到本机以外、暂存、提交或推送。
- 页面里出现学习者自己加的内容时保留原样；`add` 只插入，不改写已有内容。

## 4. 学习者怎样打开页面

每次会话第一次发指路时，按当前环境给出一种打开方式。查看方式和页面位置属于环境，不写进学习者画像；画像里只记
“长讲解偏好用课程网页”这一条讲解偏好（画像归 `guide-learning` 维护，写入要确认）。

1. **本机运行的 Agent**：给出页面的绝对路径或 `file://` 地址，用浏览器打开；之后的更新刷新即可。
2. **远程机器、容器或编辑器远程开发**：浏览器打不开远程的 `file://`。征得同意后在后台运行
   `lesson_pages.py serve --in <页面目录>`，它只在 127.0.0.1 上只读地提供这个目录，目录列表只列课程网页；编辑器的
   端口转发会把它带到本机，用浏览器或编辑器内置浏览器打开 `http://localhost:8765/<ID>.html`。服务只接受以
   localhost 或 127.0.0.1 访问；转发后是别的域名（打开时 403“unexpected Host header”）时，用 `--allow-host <域名>`
   加上它。这样打开时，页面有新内容会在底部提示刷新，不会自动刷新打断阅读。服务不会自己退出，会话结束时由 Agent
   停掉这个后台进程，下次需要时再提议。
3. **宿主能发布私有页面**（例如生成可分享链接的页面功能）：页面内容会离开本机，必须学习者明确同意，涉及私有源码或
   资料时尤其要说明。仓库里的文件仍是正本，发布的只是副本；一课保持一个链接，在每段追加后更新。分了页的课每页
   各一个链接，改了哪页就更新哪页（`continue` 也改上一页，还有输出 `directory_refreshed` 里的页）；副本里的跨页链接可能打不开，指路时给出那一页的链接。

指路里的链接用所选方式下能打开的地址，同时写出块名；学习者在已打开的旧版本页面里点新块的链接时，页面会自动重新
加载。页面里的阅读位置和看过的版本按 `new` 生成的页面键区分，深浅色选择对所有课程网页通用；它们都只保存在学习者自己的
浏览器里，不是学习状态。

## 5. 受管配置

`lesson-pages` 的受管配置可选；没有配置时按第 1 节的顺序找位置。配置只声明页面目录：

```json
{
  "schema": "agent-skills.lesson-pages/v1",
  "skill": "lesson-pages",
  "page_targets": [
    { "id": "triton-pages", "collection": "docs/triton-learning/pages" }
  ]
}
```

- 每个目标只有 `id` 和仓库相对的 `collection`；目录之间互不包含，大小写不同也算重复。不接受自由文本、命令、
  路径之外的授权字段。
- 配置要求同一宿主上也选择了 `guide-learning`。目录不能与任何其他 Skill 的写入目录
  重叠。
- 目录是写入上限，不是授权，也不是扫描许可。

## 6. 与已有页面和其他产物

- 仓库里早先手工做的图解页不归本 Skill 管：不加标记、不改写；新页面可以在相关节点链接它们。要继续修改旧页时，
  按普通文件修改另行确认。
- 页面可以被学习记录引用；只有用户明确指定时，才作为文章、卡片或英语回顾的素材。页面完成不触发任何下游 Skill。
- 页面不写进计划、账本或断点；`guide-learning` 的结课、恢复和练习规则不因页面而改变。
