# 长内容、窄屏与连续滚动检查

建页、增加部件、修改布局或脚本时读。`check` 校验结构与脚本语法，浏览器验证实际阅读行为；二者不能互相代替。
纯文字修改通常只检查受影响段落，已有检查通过后，仅因新改动、失败或未解决的疑点而扩大或重复验证。

## 1. 先保住内容与结构

- 重构前后比较题目、原答、反馈、来源版本、文件集合、源码行号链接和已有锚点；展示变化不应悄悄修改这些事实。
- 独立问题拆成列表，条件放在问题之前；代码树与说明区从同一份结构生成，不分别维护两份易漂移的事实。
- 用 `outline` 定位修改块，只编辑本页样式／声明式内容，勿手改生成的基础运行时。
- `<script data-lp-hook>` 只注册函数。写入工具把它们移出正文，排在 `#lp-runtime` 之前；遗留页可用 `render` 修复。
  批注参照应是可见内容，必要时用 `data-note-for` 指定前面的同页锚点。脚本、样式、模板和隐藏元素不能作为测量基准。

## 2. 长内容与组件宽度

在 390、768、1280 像素视口和浅色／深色下看受影响部件；有断点或布局算法时再检查切换边界两侧。
不要仅验证浏览器宽度：正文栏、批注栏和部件内边距会进一步压缩实际空间。

| 对象 | 需要主动放入的边界内容 | 通过条件 |
| --- | --- | --- |
| 选项组 | 足够多的选项、一个较长标签、切到第二行 | 按钮均可点击，选中背景只覆盖所选按钮，文字对比清晰 |
| 数据读数 | 最长数字＋单位、不同量级、全部卡片 | 数字与单位完整成组，卡片不越界；必要时改竖排，极长内容在自身区域可操作 |
| 文件树 | 深层目录、长文件名、相同basename、最后一项 | 树不撑宽整页，完整路径可在说明里读到，末项可达 |
| 时序图 | 最长状态／信号说明、不同参与者槽数 | 状态不重叠，控件可到达，局部等待不会被误画成全局完成 |
| 表格／公式 | 最宽列、最长公式、长来源路径 | 在自己的容器内处理宽度，整页不出现横向滚动 |

单独测缩放或改变字体后可能失效的固定数字。例如两栏顶距应来自共同布局，而不是为一个截图手调坐标。
玻璃等外观仅在选择该风格时检查：相关面板共用边框、内边距和材质，文字与选中态不能随透明度一起变淡。

## 3. 连续滚动回归

这一步使用**正常动画**；只在减少动态效果下截图，会漏掉滚入动画和延后布局触发的问题。

1. 用新的隔离浏览器上下文打开页面，确认没有旧滚动位置或 hash 干扰。等待字体与首屏动画就绪；批注不应出现在封面。
2. 从相关图前开始连续滚过图、来源批注、下一节；每经过关键位置停留超过滚入布局的延迟，再继续向下和返回。
3. 展开／折叠目录、切换仓库或面板、改变视口之后重复受影响的一段。组件内选择只滚动它自己的目录窗口，不能抢走整页位置。
4. 比较图和批注的文档坐标、前段间距与页面高度。动画的小位移会消退；没有用户展开内容时，间距不能持续膨胀，后文不能被反复推走。
5. 若出现“自动跳回”，先区分实际导航调用与布局位移。检查 hash／`scrollTo`／`scrollIntoView`，再查测量锚点、float/clear、
   ResizeObserver 与 `lp:layout` 的相互影响；不要先关闭动画、加滚动锁或强制滚回原位来掩盖根因。

自动几何检查可以发现回归，但人工仍要看图是否易读。测试时保存的截图、临时页和日志放在临时输出目录，
不把测试运行记录混进课程进度或证据。

## 4. 交互、无脚本与视觉

- 从首次状态操作到最后，测试直接跳步、回退再前进和切换仓库；状态、标题、说明及连线应一致。
- 键盘可以到达可见控件，焦点清楚；目录关闭后，隐藏子项不再接收焦点。没有完整树控件键盘协议时，使用原生 details／链接即可。
- 手机触控目标不小于44px；目录或表格内部滚动时，末项和说明入口可达。不要通过自动跳页替代清楚的操作入口。
- 无脚本时保留完整提纲或全部步骤，打印时恢复需打印的内容；减少动态效果保留操作，只去掉动画。
- 同时看浅色正文、深色正文与实验台的文字／图标／连线对比。源码浏览器选中项的文字和右侧标题也要能说明关联，连线不是唯一线索。
- 看控制台和部件自检错误。修复后再次验证受影响路径；已通过的其他内容不必无条件全部重跑。

## 5. 可复用浏览器检查函数

[`scripts/browser_checks.js`](../scripts/browser_checks.js) 是接受 Playwright Page 的函数表达式，默认在隔离上下文中
检查当前**本地课程页**，不清除或改变读者现有页面的存储、主题、历史和滚动位置。它不会启动服务，也不会访问外部网站。
先用现有浏览器工具打开授权页面；本地文件查看按宿主支持方式设置，启动 `serve` 仍需用户已有同意。

用 `playwright-cli` 时：

```bash
playwright-cli -s=lesson-review run-code --filename=<Skill目录>/scripts/browser_checks.js
```

默认使用三种宽度、浅深主题及正常动画，检查首屏批注、页面横向越界、选中背景、读数容器，以及少数代表图滚动停留后的布局稳定性。
返回 `ok`、逐组合结果和 `issues`，默认不写文件。它还返回 `visualReviewRequired=true`，不能据一个 `ok` 宣称视觉和全部交互都已通过。

在支持直接调用函数的浏览器测试环境中，第二个参数可传：

```js
{ widths: [390, 1280], themes: ['light', 'dark'], anchors: ['fig-4-1', 'fig-5-1'], settleMs: 1100 }
```

`maxLandmarks` 限制默认滚动检查数量；`anchors` 明确只检查当前变化涉及的位置。用户需要保存截图时可传 `screenshotDirectory`，
先选择临时或已授权目录。没有能创建隔离上下文的浏览器工具时，按前面的手动清单做；完全没有浏览器时只报告结构检查结果，
明确“未在浏览器中验证”。
