## 1. 页面是什么品类

课程网页是阅读型的技术讲义，参照的是 Distill、Bartosz Ciechanowski、Red Blob Games 一类可交互的讲解文章：
一栏好读的正文，图和部件紧挨着讲它的那段文字，来源放在页边。北极星是“安静的讲义，发亮的实验台”：正文在浅纸上
安静易读；能动手的图和代码放在深色台面上，与正文形成反差；检查题是全页最醒目的色块；朱红只出现在导师指给你看的
地方，符号色把同一个量从正文连到公式、代码和图。页头是一条深色封面带，首屏仍以标题和导入为主；不做落地页那种
滚动叙事、视差和自动轮播。

## 2. 一种元素一种样子

| 元素 | 样子 |
| --- | --- |
| 页头 | 深色封面带：面包屑、标题、主线资料与阅读时间、“本次新增” |
| 导入 | 纯叙述，第一段字号略大，不加框 |
| 骨架 | 地铁线路：讲过的站通车可点，换乘站列出各节，没讲的站“未开通”并蒙雾；节点开头挂站牌 |
| 节点标题 | 编号徽标与标题同一行，宽屏时悬挂在左边距；读到哪一节，徽标就亮起；标题上方不放标签 |
| 结论 | 节点第一段，字号略大，以深色“结论”标签开头；全节点唯一的强调 |
| 讲解层次 | 段首朱红小圆点加墨色层次名，不给每层单独的标题、图标或框；边界一层加 `lp-aside` 退为灰色 |
| 来源与版本 | 每节点一条页边批注，窄屏时紧跟所属段落 |
| 边界 | 一段普通文字，不用警示色 |
| 面试怎么讲 | 全页唯一一种引用块：浅底圆角、朱红引号，注明时长 |
| 检查题 | 全页最醒目的色块：开放时朱红描边、实心朱红题头条，条上写“在对话中回答”；作答后退为浅灰底 |
| 补充 | 缩进在所属节点下，左侧一条虚线，标题前有“补充”标记，写明回答哪道题后补上 |
| 图 | 静态图用浅底画布；分步演示、对照切换、参数探索放在深色实验台上；下方编号说明；宽图在宽屏时伸进批注栏 |
| 公式 | KaTeX 排版，行间公式居中、过宽时在框内滚动 |
| 代码 | 深色台面、语法着色、行号、代码头与复制；讲到的行朱红底，行注带编号 |

## 3. 可以用的令牌和类

颜色只用令牌：`--paper`、`--raised`（图与代码的浅底）、`--ink`、`--ink-soft`、`--ink-faint`、`--rule`、`--accent`、
`--accent-ink`、`--accent-wash`、`--mark`、`--focus`（焦点框），以及符号色 `--s1`–`--s4`（对应类 `lp-s1`–`lp-s4`）。字体令牌
`--font-sans`、`--font-mono`、`--font-math`、`--font-kai`（楷体只用于批注的“注”），圆角 `--radius`、
`--round`。实验台和代码块里同一批令牌自动换成深色版本，部件样式不用分两套；静态图想上台时给 figure 加 `is-stage`。

常用类：`lp-canvas`（图的画布，在实验台上透明）、`lp-table`（可横向滚动的表格容器）、`lp-flow`（阶段链，按宽度自动均匀分行，
窄时竖排）、`lp-output`（编译器或终端输出）、`lp-out` 与 `lp-readout`（读数）、`lp-btn`、`lp-seg`、`lp-controls`、
`nb`（不换行）、`lp-path`（长路径可断行）、`lp-tag`、`lp-dim`（分步演示里淡影预告后面的状态）、`lp-pen`（导师
划线，每节至多一处）、`lp-ring`（圈注，见 page-structure.md）、`lp-aside`（可跳过的深挖段落），以及术语注音的 `<ruby>`。
页面专用样式写在片段的 `<style data-lp-style>` 里，类名带上本页前缀；需要调整模板组件的布局时，加一个带本页前缀的
修饰类，不改模板的类本身。

## 4. 自绘图形

- 先考虑能随宽度重排的 HTML 结构：阶段链、网格、表格、并排的小方块。只有真正讲空间关系的图才用 SVG。
- SVG 写 `viewBox`，宽度按正文栏设计；文字在 390 像素宽的屏幕上不小于 12 像素，也就是字号 × 342 ÷ viewBox 宽（实验台在手机上约 342 像素宽）
  ≥ 12，太宽就另做竖版。`check` 只看 `<text>` 的 `font-size` 属性；写在样式里的字号自己核对。
- 颜色只用 `currentColor` 或 `var(--…)`，不写色值或颜色名；这样深色模式下图仍然看得清。`check` 会拒绝 SVG 的
  `fill`、`stroke` 等属性里的色值和颜色名，提示样式里的十六进制和 `rgb()` 一类色值；样式里的颜色名要自己核对。
- `<svg role="img" aria-label="这张图说明了什么">`；图里的字与正文同一字体，关键量用同一种符号色。
- 一张图只讲一件事，说明写在 `figcaption` 里；图已经说清的，正文不再重复。

## 5. 版面与文字

- 版面三档：1280 像素以上是目录、正文、批注三栏；1100–1279 是正文和批注；更窄时单栏，批注回到正文。学习者常把
  页面放在对话旁边，768 像素左右也要好读。
- 正文 17 像素、行高 1.75，窄屏 16.5 像素；不要把任何正文改到 13 像素以下，也不要压缩行高来塞内容。
- 数字和单位、变量和取值不拆行：页面加载时会自动把“128 MiB”“k = 8”这类片段包成不换行；形状等其他记号自己用
  `<span class="nb">[T, k]</span>`。长路径和提交号放进 `lp-path` 或 `code`。
- 表格、代码和公式在自己的容器里横向滚动，整页不出现横向滚动条。`check` 不量 TeX 公式的宽度：行间公式在 390 像素
  下自己看一眼，过宽就用 `aligned` 拆成多行。
- 段落以读得顺为准，单段约 220 字以内；信息太多就拆段、改成图，或把细节放进已讲内容的 `<details>`。

## 6. 颜色与动效

- 朱红是导师的笔，也是“该你动手”的信号：导师划线、圈注、可调段落、批注的“注”、讲解层次的小圆点、代码里讲到的行与行注编号、开放题、
  部件的主按钮，以及图里导师要你注意的那一处；模板自己的节点编号、骨架圆点、“你在这里”的描边、进度条和目录指示也用它。片段自己再用朱红时，一屏里不超过三处。
- 一课里的两三个关键量各绑定一种符号色，全页不变；颜色永远伴随符号文字，不单靠颜色区分。
- 模板负责页面级动效，各只做一次：封面标题升起、封面网格上扫过一道光、图和题目块滚入视野时淡入、骨架逐点画出、新通车的站散雾、导师划线和
  圈注一笔画出、可调段落第一次读到时拨盘轻摆并浮出提示、开放题的标记轻闪三下、阅读进度条和目录指示随滚动移动；部件包里的海报数字数一次、
  误解被划掉一次、公式解剖的引线画一次，从链接打开时目标亮起两秒多。片段自己的动效只解释变化：按下反馈 150–200 毫秒，演示一步的变化
  300–600 毫秒，主体先动、相关元素晚 40–80 毫秒跟上；可以被打断，终态保留静态的变化标记；不做循环装饰。系统开启
  “减少动态效果”时一切直接到位，没有脚本或打印时内容全部可见。

## 7. 不要做的事

这些是模型常见的默认做法，在讲义里只会添乱：标题上方的小标签或编号标签；卡片一侧的彩色粗边线；渐变文字；
封面和实验台已经有光、网格和阴影，片段里不再自加发光、渐变底或投影；卡片里再套卡片、每层都画框；用表情符号当图标；中文页面里的英文大写标签；同一处叠两条
分隔线；页头的元数据胶囊；页面上写“示例”“示意图”“仅供参考”这类制作说明；为了配平版面而写的空泛句子；把张量画成
立体方块：维数常多于三，写清有几维、各维的含义和大小（如 [批, 头, N, d]）即可，涉及具体算法时画计算图。

## 8. 视觉检查

建页、加了新的图或部件类型、写了自定义脚本时，用宿主现有的浏览器工具检查新增部分：

1. 在 1280、768、390 像素宽度各看一次，浅色和深色各看一次；页面用了蓝图或朱批时就在那种风格下看；
2. 文字没有重叠、截断或被压住，整页没有横向滚动，SVG 文字在 390 宽度下读得清；
3. 深色模式下，以及浅色模式的实验台里，图形、符号色和标记仍然看得见；
4. 把部件从头到尾点一遍，控制台没有报错，自检用例没有报错；
5. 缩到一半大小看一眼，主角是否清楚、一屏里是否只有一个重点。

以 playwright-cli 为例：`playwright-cli open <页面地址>`，`playwright-cli resize 390 844`，
`playwright-cli screenshot`，`playwright-cli console error`，看完 `playwright-cli close`。没有浏览器工具时如实说明
“未在浏览器中验证”。

## 9. 三种风格

风格只换外观，片段写法完全相同：不为某种风格写专用标记，片段样式只用令牌，三种风格下都成立。

| 风格 | `--look` | 样子 | 适合 |
| --- | --- | --- | --- |
| 讲义 | `handout`（默认） | 本参考前几节所述 | 大多数课 |
| 蓝图 | `blueprint` | 白图纸网格，蓝图色封面与实验台；图框、空心标题、标题栏写图号与版次，新内容是修订三角；骨架是双线管线图 | 系统、硬件、算子、架构 |
| 朱批 | `vermilion` | 宣纸、墨与朱砂；汉字节号，导师划线变成字下的圈点，批注写“批”，题目后钤“第 N 课”印，检查题是试卷框加状态印 | 偏阅读、理论与推导 |

- 一门课一种风格。建这门课的第一页时选定：学习者指定的为准，否则默认讲义，课程性质明显时可在开课确认里用半句话提出
  另一种；之后用 `find` 看已有页面的 `look` 沿用。印章取面包屑里的“第 N 课”，图号取页面 ID。
- 学习者要换风格时，对这门课的每一页运行 `look --to <风格>`，升一个版本，内容不变。风格样式放在 `#lp-look` 里，不手改；
  `check` 对它报 `runtime.drift` 时运行 `look --to <当前风格>` 刷新。
