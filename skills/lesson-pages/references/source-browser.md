# 双栏源码浏览器

需要沿真实目录定位文件、解释职责并链接固定源码时读本参考。它与系统结构图 `lp-zoom` 分工不同：
目录树回答“文件在哪里”，右侧说明回答“它负责什么、应读哪些行”。完整可写片段见
[example-source-tree.html](example-source-tree.html)。

## 选材与呈现

- 从本课已选定的源码版本取目录与文件，不扫描整仓库来凑满树。父目录必须真实，行号对应同一提交或版本；
  移动分支名不能单独作为实现依据。版本与来源结论仍由 `guide-learning` 核验。
- 树中只放目录／文件名与层级线；职责和行号放进关联说明区。用 `context` 保留必要的旁支位置，避免每个文件都是大卡片。
- 可在一个部件中比较多个仓库，运行时生成仓库按钮；没有固定“五个仓库”或固定文件数量要求。
- 默认沿用课程风格。用户要求参考图中的磨砂材质时，在 figure 加 `is-glass` 类，两个关联窗口使用同款表面。
  玻璃是可选外观，不改变内容结构，也不要求所有课程使用它。

## 声明式合同

外层为带稳定 `id` 的 `figure.lp-figure.lp-source-tree`，通常加 `is-wide`。直接子级为一个或多个
`section.lp-source-repo`，最后是图注。不要另外写 tabs、右侧内容副本、SVG连线或选择脚本。

| 元素 | 必需内容 |
| --- | --- |
| `section.lp-source-repo` | 唯一 `id`；可选 `data-start` 指向本仓库起始节点 |
| `h4` | 仓库显示名；可在其中链接仓库固定版本根目录 |
| `p.lp-source-version` | 可见的版本或完整提交号 |
| `p.lp-source-about` | 本仓库在课程主线中的职责 |
| `p.lp-source-docs` | 可选的资料链接 |
| `ul.lp-source-outline` | 本仓库唯一的根提纲 |

每个目录节点是提纲中的 `li`，带唯一 `id`、`data-kind` 和 `data-path`；直接子级 `<b>` 写名称，
`<p>` 写职责。`data-path` 使用仓库相对路径，子节点路径必须属于父目录；文件名相同也以完整路径区分。
可选 `data-main="true"` 将该节点列为阅读主线入口。

| `data-kind` | 子内容 |
| --- | --- |
| `dir` | 一个直接子级 `ul` 放真实子节点；可展开 |
| `file` | 一个 `ul.lp-source-links`，每个 `li` 直接放有文字的源码链接，至少一项 |
| `context` | 仅名称与说明，用来淡化展示本课不展开的旁支目录 |

一个文件可以有完整文件入口和多个重要行段。使用可移植相对链接或固定版本网页链接，不写机器绝对路径。
下面是同一个文件节点的全部事实，不需要再给右侧写一份：

```html
<li id="json-encoder" data-kind="file" data-path="Lib/json/encoder.py" data-main="true">
  <b>encoder.py</b><p>将 Python 对象逐步编码为 JSON 文本。</p>
  <ul class="lp-source-links">
    <li><a href="https://github.com/python/cpython/blob/v3.12.0/Lib/json/encoder.py">固定版本文件</a></li>
  </ul>
</li>
```

## 运行时与降级

运行时保留节点 id，生成紧凑的原生 `details/summary` 与文件选择链接，再从同一节点生成职责说明。
选目录会展开／折叠；选文件只更新说明；“定位主线”展开所需父目录并只滚动目录窗口。
只有用户明确点击页内位置链接，才使用正常页面导航。源码链接独立打开，不与选择动作混在一起。

连线是辅助：选中行和说明标题都有文字，连线不承载唯一信息；窗口滚动、目录展开及尺寸变化后按真实元素位置重画。
看不到起点或窄到单栏时隐藏连线。手机先树后说明，提供到达说明区的入口；触控和键盘均须可到达最后一项。

无脚本时原提纲包含全部职责与来源；打印展开目录并恢复完整说明。不要把事实只放在运行时数据对象里，
也不要用不完整的 ARIA tree 冒充原生键盘行为。

## 检查

`check` 会检查仓库元信息、节点类型、路径关系、源码链接及本仓库 `data-start`。浏览器按
[browser-checks.md](browser-checks.md) 核对：切换仓库、目录展开、文件选择、说明定位、长文件名、
单栏末项可达性与连线位置；排版改造前后的文件集合、版本和来源链接应一致。
